# Состояние разработки — 19 октября 2026, версия 2.1.0

Это передача контекста между рабочим и домашним чатами. Источник кода — main этого репозитория.
Сначала проверь git status и обнови локальную копию; старую папку с несохранённой работой не удаляй.

## Архитектура

Переносимое C# WinForms приложение. Build.ps1 компилирует против reference assemblies .NET Framework 4.6
и встраивает помощники x86/x64 в один EXE. Имя результата Build.ps1 оставлено совместимым:
bin/Bars Service Manager 3000.exe. Общий лаунчер называется BARS Manager 3000.

- ManagerHub.cs — лаунчер, темы, навигация. «В меню» возвращает лаунчер; крестик закрывает приложение.
- Program.cs и Service*.cs — менеджер служб, -i/-u, HttpService с выбранной Windows-учётной записью,
  хранение через DPAPI, список служб, сбор логов по датам в ZIP. Ранее согласованные функции сохранены.
- LibraryManagerForm.cs — Bars Component Manager 3000, выбор строки/чекбоксов, выбрать всё/снять выбор,
  рекомендации, очереди, подтверждение отмены и выхода.
- LibraryCatalog/Discovery/Core/Versions/VcProfiles/Maintenance — источник, обнаружение и версии,
  зависимости, точные штатные команды удаления. LibraryInstaller/Heartbeat/Cancellation — повышенный
  помощник, защищённый канал и сигнал отмены, дерево процессов через Windows Job Object.

## Что сделано в 2.1.0

Модуль компонентов переименован везде в Bars Component Manager 3000. Кнопки лаунчера выше и имеют отступы.
Таблица показывает версию в комплекте и в системе, краткую рекомендацию и полные сведения в подсказке/отчёте.
Старые совместимые версии предлагают обновить; более новые пропускаются. Учитываются все числовые
части версии. .NET 6/8/9/10/11 разделены по ветке major.minor, семейству, архитектуре и каналу RC/Preview.
Файлы после удаления без действующей регистрации не считаются установленным runtime.

RuntimePack_Full_v21.7.30 исключён, в том числе из старого кэша. Встроенный RuntimePack Lite 20.3.3
обязателен в обоих профилях единственного EXE сборника VC++:
- старый профиль: v0513,v0513\silent,rtl (устанавливает 2005–2013; требуемый мониторинг 2012/v11 и 2013/v12);
- современный: v1522,v1522\silent,rtl (текущий v14; без принудительной установки старого v14).
Названия задач прочитаны из заголовка текущего EXE, не взяты на веру из старых CMD.
Текущий SHA-256 VC EXE: 4E7483652C94AA470B4D943975E2D75F4D3457D8ECCC502F0135EDCF66A81220.
Состояние профиля подтверждает проверяемые VC++, но не полный состав Lite. Если выбраны оба профиля,
EXE запускается дважды; задача Lite включена в каждом вызове. Это оговорено в руководстве.

Версия VC2012 package 11.0.61030.0 отличается от его CRT DLL 11.0.51106.1 — нельзя брать минимум
этих двух номеров как одну версию. Пакет сравнивается по активной регистрации; DLL подтверждают поколение.
Modern VC распознаётся и под именем Microsoft Visual C++ v14 Redistributable.

В текущем C:\Библиотеки 39 поддерживаемых файлов и 40 логических строк из-за двух профилей VC.
Числовые префиксы и пути изменены пользователем. Сканирование из метаданных это поддерживает.
Папку библиотек запрашиваем только при установке. Проверка и штатное удаление работают без неё.

Отмена передаётся защищённым событием между UI и повышенным помощником; не ждёт свободного pipe.
Сначала WM_CLOSE только своим окнам, через 2 секунды TerminateJobObject только своего дерева.
KILL_ON_JOB_CLOSE убирает дочерние процессы при аварийном выходе помощника. Проверка/копирование
файлов прерываются между блоками. Выход подтверждается и после очистки закрывает программу;
«В меню» после подтверждения возвращает лаунчер. Общая служба Windows Installer не завершается.

## Проверки и ограничения

Полный Test.ps1 пройден: 1829 проверок, включая 14 по отмене и 68 по UI/навигации; обе темы и навигация проверены. Тесты отмены используют только собственные
инертные EXE: быстрый родитель и долгий дочерний процесс, обычное закрытие окна, принудительная остановка,
аварийный выход контроллера; посторонний процесс с тем же именем остаётся работать. Для проверок ACL
нужен обычный пользовательский токен Windows, урезанный токен песочницы может запрещать OpenExisting.

На рабочем компьютере read-only обнаружение подтвердило 40/40 строк, включая .NET 11 RC и современные
более новые патчи .NET. Подготовленные команды удаления проверены без выполнения; MSXML предоставлен ОС.
Исправление ERROR_INVALID_NAME 123 из 2.0.3 сохранено: пустой WorkingDirectory передаётся CreateProcess как NULL.

Реальные установки, обновления и удаления этой версией НЕ прогонялись. Нужна чистая тестовая VM,
особенно для отмены сторонних тихих установщиков, отката MSI и последующего восстановления/удаления.
Принудительная остановка не гарантирует откат; серверная часть Windows Installer может продолжить
операцию или откат вне дерева менеджера. Не обещай универсальную атомарную отмену любого EXE.
Полной матрицы Windows 10/11 и Server 2019+ нет. Server Core/ARM64 не проверены.

Все свежие файлы релиза неподписанные. Прежний .cer в signing содержит только открытый сертификат;
закрытый ключ/пароль через Git не переносим. Данные автора в AssemblyInfo.cs заданы пользователем,
их без просьбы не заменять. Шутка в «О программе» также пользовательская.
