# 2.3.54 — нижняя граница таблицы установщиков .NET

Без подписи, .NET Framework 4.6. Незанятая область DataGridView установщиков .NET теперь использует Canvas окна, а строки сохраняют Surface. Устранена светлая/зелёная полоса под последней строкой; боковые границы и поведение прокрутки сохранены. Другие таблицы не менялись.

Снимок просмотрен. Полный Test.ps1 не запускался; физические DPI/КСО не испытывались. Сетевые проверки/скачивание/установки не выполнялись. Прежние ограничения проекта сохранены.
