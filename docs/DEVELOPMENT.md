# Разработка и сборка

C# / WinForms. Текущее экспериментальное направление — .NET Framework 4.8. Готовая программа собирается в один EXE со встроенными помощниками x86/x64.

## Перед изменениями

Прочитай [AGENTS.md](../AGENTS.md), [состояние разработки](../DEVELOPMENT-STATE.md) и описание текущего выпуска. Сохраняй пользовательские изменения и тексты.

## Локальная сборка

Из корня проекта в Windows PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-OneFileRust.ps1 -OutputDirectory .\bin
```

`Bypass` действует только на запускаемый процесс. Сборка по умолчанию без подписи. Reference assemblies подготавливаются скриптом автоматически; при первом запуске может требоваться сеть.

## Проверки

`Test.ps1` и целевые сценарии находятся в `tests`. Полный сценарий содержит проверки, требующие подготовки среды: не запускать реальные установки и системные изменения на рабочем компьютере. Условия и ограничения перечислены в [состоянии разработки](../DEVELOPMENT-STATE.md).

## Выпуски

Вложения релиза: один EXE, RELEASE-версия.md и CHANGELOG.md. Без Portable-архива и личных памяток. Исходники, ресурсы и тесты хранятся в репозитории; внешние установщики, секреты и содержимое work не публикуются.
