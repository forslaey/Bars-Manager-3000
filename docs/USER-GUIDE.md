## Начало работы

BARS Manager 3000 объединяет шесть инструментов: менеджер служб, менеджер библиотек, установку программ, распаковку утилит, первичные системные настройки и логи программ BARS. Компоненты Windows открываются из менеджера библиотек. Отдельная кнопка «Скачать комплект» в главном окне позволяет получить библиотеки и утилиты с Яндекс Диска или Google Диска; скачивание не запускает установщики.

1. Запусти EXE менеджера и выбери нужную карточку в главном окне.
2. Проверь выбранный файл, папку или строку перед действием.
3. Изменения запускаются кнопками соответствующего модуля. Если Windows запросит права администратора, проверь действие и подтверди запрос.
4. Дождись результата и прочитай журнал. Успешное завершение стороннего установщика само по себе не заменяет проверку результата.

В одной сессии Windows можно открыть один экземпляр BARS Manager 3000. Повторный запуск переводит фокус на уже открытый менеджер. Лаунчер остаётся доступен при работе в модулях и в их диалогах. Повторный выбор карточки переводит фокус на уже открытый модуль. «В меню» переводит фокус на лаунчер. «Закрыть» закрывает только текущий модуль. «Закрыть программу» в лаунчере завершает работу всех модулей. Если идёт активная операция, менеджер покажет предупреждение.

В фирменных окнах выбора пути одно касание выделяет строку, двойное касание открывает папку или подтверждает выбор файла в режиме открытия. Мышью можно открыть строку двойным щелчком. «Перейти» открывает выделенную папку или введённый вручную адрес. «Выше» открывает родительскую папку. Боковые кнопки мыши «Назад» и «Вперёд» переключают папки по истории. Свайп прокручивает список.

Значок темы переключает светлое и тёмное оформление. Выбор сохраняется для следующих запусков. В окнах без переключателя оформление наследуется от приложения. Квадратная кнопка ⓘ открывает сведения о программе и авторе. Пока это окно открыто, заблокирован только лаунчер.

Папка комплекта по умолчанию — C:\BarsManager3000. Можно указать другой корень. В нём находятся _libraries, _soft, _tools и _wallpers. Установщики .NET размещаются в Microsoft .NET внутри _libraries. SQL-наборы лежат в _soft\_SQL, а установщик .NET Framework 4.8 для запуска менеджера — в _barsmanager3000.

При отсутствии .NET Framework 4.8 запускатель сначала ищет установщик в _barsmanager3000. Если файла нет, укажи локальную папку или выбери Яндекс Диск, Google Диск либо Microsoft. При выборе Microsoft откроется страница в браузере. После скачивания из облака дождись проверки файла и нажми «Установить». Современные .NET Runtime и ASP.NET Core Runtime устанавливаются отдельно, если они нужны конкретным службам. Права администратора запрашиваются для действий, которым они необходимы.

## Службы: установка и удаление

Модуль управляет службами BARS на текущем компьютере.

### Установка

1. Выбери EXE службы или перетащи его в область выбора файла.
2. Проверь найденную регистрацию. Если её нет, нажми «Установить службу».
3. При необходимости открой «Настройка установки». Обычный режим вызывает EXE с ключом -i; отдельный режим .NET предназначен для совместимых служб с выбором учётной записи. Не выбирай его для произвольного EXE.
4. Подтверди запрос Windows и дождись повторной проверки регистрации.

При установке DK.Fiscalization.Agent.Atol.exe открывается «Проверка совместимости». Разрядность драйвера ККТ должна совпадать с разрядностью агента. Если требования удалось прочитать из конфигурации агента, окно покажет нужные версии .NET. Сверь их с установленными компонентами перед продолжением.

### Удаление

Выбери EXE и проверь связанные службы перед «Удалить службу». Менеджер проверяет состояние связанных служб и при необходимости останавливает их перед удалением. Обычный режим использует ключ -u. Если один EXE зарегистрировал несколько служб, процедура может удалить их все. Удаление регистрации не является удалением всех файлов программы.

### Учётная запись

В настройках установки можно выбрать пользователя Windows. Запоминание пароля необязательно; сохранённые данные привязаны к текущему пользователю и компьютеру. Не передавай свои настройки другим людям.

Если не найдена совместимая версия фреймворка, проверь требуемое поколение и разрядность .NET Runtime и ASP.NET Core Runtime. Более новое поколение не заменяет требуемое. При удалении менеджер может предложить отдельно удалить регистрацию одной подтверждённой службы средствами Windows, без запуска её EXE; файлы и настройки останутся.

Отменить ожидание можно и в очереди, и во время предварительной остановки службы. Если Windows уже получила команду остановки или удаления, действие может завершиться после отмены ожидания. Проверь регистрацию повторно и прочитай журнал. Если процедура удерживает очередь, менеджер показывает имя службы. Через две минуты ожидания новая системная операция завершается без запуска. Очередь освобождается после выхода текущего процесса.

Сведения о разрядности и подписи читаются из выбранного файла без его запуска. Подпись относится к файлу, а не к PID работающего процесса. Если файл недоступен или данные не удалось прочитать, это не подтверждение совместимости или доверия.

## Службы: управление и состояния

Выбери строку в таблице: действия выполняются для этой службы. «Запустить» запускает её, «Остановить» останавливает. В поле «Режим запуска» выбери нужный вариант и нажми «Применить». Для изменения Windows может запросить права администратора.

«Обновить статус» повторно читает службы Windows. Переключатель проверки каждые 10 секунд включает автоматическое обновление, пока модуль открыт. «Открыть службы» открывает стандартную оснастку Windows.

Что означают состояния
«Работает» — Windows сообщает, что служба запущена. Это ещё не подтверждает её реальный отклик. «Остановлена» — служба не запущена. «Запускается», «Останавливается» и «Возобновляется» — переходные состояния. «Приостановлена» — выполнение приостановлено. «Не проверено» означает, что свежего подтверждения нет. При ошибке чтения может остаться последнее известное состояние: оно не считается свежей проверкой.

Под заголовком состояния нет повторных подписей. Подробность сообщения можно прочитать при наведении на заголовок; подробности ошибок и предупреждений также попадают в журнал.

Чтобы перезапустить службу вручную, сначала останови её и дождись подтверждённой остановки, затем запусти и проверь результат. Не выполняй перезапуск во время важной операции службы без согласования.

## Службы: сбор логов и ошибки

1. Выбери службу в таблице.
2. Нажми «Собрать логи».
3. В окне сбора выбери режим: «Все логи», «Только за сегодня» или «Выбранные даты». Для последнего отметь нужные папки дат. Кнопка «Выбрать путь...» задаёт место сохранения ZIP.
4. Дождись сообщения о сохранении архива. Сбор не требует остановки службы.

При отмене незавершённый ZIP не сохраняется. Если файлов нет или они недоступны, прочитай сообщение об ошибке и проверь путь и права доступа.

Журнал текущего сеанса показывает действия менеджера и их результат. Это не постоянный монитор внутренних ошибок службы и не замена её собственным логам. Перед передачей архива проверь, нет ли в нём паролей, персональных данных и настроек подключения.

Если действие завершилось с ошибкой, прочитай подробности в журнале, обнови статус и при необходимости открой оснастку служб Windows. Если Windows не подтвердила ожидаемое состояние, не считай действие завершённым успешно.

Код 1064 означает внутреннюю ошибку службы при обработке команды Windows. Если ошибка возникла при запуске, появится сообщение «Служба не запустилась из-за внутренней ошибки». Нажми «Собрать логи» и проверь записи за время попытки. Если записей нет, проверь журнал «Приложение» в просмотре событий Windows. Код 1053 означает, что служба не ответила вовремя. Обнови статус и проверь журнал службы.

Режим «Все логи» собирает TXT и LOG из Logs, включая вложенные папки. «Только за сегодня» определяет дату по имени папки. В режиме выбранных дат можно отмечать несколько папок; выбор сохраняется при переходе между страницами.

## Ход операций и загрузки

В загрузке комплекта, программах, обновлениях .NET, распаковке утилит, системных библиотеках и первичных настройках используется единая полоса: этап и процент сверху, сведения о выполненных задачах или скачанных байтах ниже. Имя файла, скорость и примерное оставшееся время отображаются там, где есть соответствующие данные. При открытии модуля полоса неподвижна. Фоновая проверка программ и первичных настроек не означает подготовку установки; после проверки движение не остаётся включённым. Тонкий скруглённый контур поддерживает обе темы. Полоса движется слева направо по выполненным задачам очереди. Скачивание внутри задачи учитывает реальные байты; распаковка — обработанные файлы. Если объём этапа неизвестен, достигнутая доля сохраняется до подтверждения результата, без бегущего сегмента. Проверка файла, подписи и сохранение новой копии показаны отдельными этапами. 100% и «Готово» появляются после успешной проверки и сохранения. Установщик без собственных процентов показывает название этапа; общая доля увеличивается только после подтверждения его результата. Доля задач не означает долю оставшегося времени: задачи могут длиться по-разному.

В загрузке комплекта показан общий объём очереди и количество готовых файлов, в сверке — проверенные файлы. Программы учитывают подготовку пакетов и подтверждённые установки; .NET — выбранные установщики и байты текущего файла. Библиотеки учитывают подтверждённые компоненты, настройки — применение и проверку результата. Скорость и оценка времени появляются после накопления данных и могут меняться. Пауза комплекта останавливает движение; отмена и ошибка не означают успешного завершения. Системное отключение анимаций учитывается. Длинное имя сокращается на экране; полный текст доступен при наведении.

## Скачивание и проверка комплекта

«Скачать комплект» открывается отдельно из главного окна. Выбери источник — Яндекс Диск или Google Диск, папку назначения и состав: «Библиотеки и .NET» либо «Утилиты BARS». Отдельно можно выбрать программы, обои для рабочего стола и SQL Server и SSMS. Если выбран раздел SQL, после чтения облака отметь нужные папки или нажми «Выбрать всё». Менеджер скачает недостающие файлы отмеченных папок вместе с вложенными файлами. Эти файлы сохраняются в комплект. Установка программ по-прежнему может проверять официальные сайты. Файлы библиотек из старой структуры облачного комплекта проверяются и сохраняются в _libraries. Проверка комплекта не запускает установщики.

После сравнения появляется окно «Результат проверки комплекта» с колонкой «Файлы» с действиями «Выбрать всё», «Снять выбор» и «Применить». Массовый выбор затрагивает только разрешённые строки. Отсутствующий файл помечается «Отсутствует - будет скачано». Если различий нет, отдельного окна результатов нет.

При проблеме источника менеджер может предложить скачать остаток из другого облака. Готовые проверенные файлы сохраняются; частичная загрузка продолжается только при совпадении файла и поддержке докачки. Новая копия проверяется до замены старой; неизвестные локальные файлы и настройки сохраняются. Скачивание, распаковка и установка — отдельные действия. Google использует публичный web-доступ, доступность которого зависит от ограничений облака.

Кнопка «Результаты» открывает результаты последней сверки, в том числе после отмены скачивания. «Перепроверить файлы» сверяет локальные файлы с уже загруженным каталогом без обращения к облаку. Повторная проверка отменяется своей кнопкой или закрытием окна. Отличающийся локальный установщик заменяется только после выбора файла и подтверждения. «Применить» в этом окне подтверждает выбор строк, а «Скачать» в основном окне начинает загрузку. «Пауза» становится доступна после подготовки источника и сохраняет данные для продолжения, «Продолжить» возобновляет очередь, «Отменить» останавливает её после подтверждения. После окончания загрузки или отмены служебная папка .bars-download удаляется. Готовые файлы остаются в комплекте. Если повторить загрузку позже, недокачанные файлы начнут загружаться заново.

## Библиотеки: проверка и выбор

Менеджер библиотек проверяет компоненты Windows и сравнивает их с выбранным комплектом. Проверка сама по себе ничего не устанавливает.

1. Открой «Менеджер библиотек».
2. Нажми «Выбрать папку…» и укажи корень комплекта или _libraries, если папка не найдена автоматически.
3. Нажми «Сканировать систему» и сравни версии в системе и в комплекте. Учитываются полная версия, разрядность и поколение компонента.
4. Отметь нужные компоненты и выбери действие. Перед запуском проверь очередь.

«Установлено» означает, что компонент обнаружен. «Не найдено» — подходящая установка не подтверждена. «Нужна проверка» означает недостаток надёжных данных. Рекомендация об обновлении учитывает сравнение версий. Более новая установленная версия не должна заменяться старой из комплекта.

Для Visual C++ доступны два профиля с обязательным RuntimePack Lite. RuntimePack Full не используется. Разные поколения и разрядности могут требоваться одновременно: наличие x64 не заменяет x86. Зависимости SQL CLR/SMO и базовый runtime для ASP.NET добавляются автоматически. После установки, удаления или переустановки TXT-журнал автоматически сохраняется в папке «Журнал установки библиотек» внутри выбранной папки установщиков. Кнопка «Открыть журнал» открывает эту папку. В журнале указаны компоненты, версии, результаты и причины остановки очереди.

«Выбрать недостающие» отмечает подходящие отсутствующие компоненты. «Выбрать всё» и «Снять выбор» работают с доступными строками. Отметку можно переключать нажатием по строке; свайп предназначен для прокрутки. Переключатель проверки каждые 30 секунд обновляет сведения, пока модуль открыт. Для локальной проверки папка установщиков не обязательна; она потребуется перед действиями с пакетами.

<a id="section-16"></a>

## Логи программ BARS

Открой карточку «Логи программ BARS» в лаунчере. В таблице видны найденные клиентские программы BARS с открытым окном. Нажми «Обновить список», если запустил программу после открытия модуля.

Выбери строку, укажи EXE через «Выбрать файл…» или выбери папку программы через «Выбрать папку…». Можно перетащить файл или папку в окно. Ручной выбор подходит и для закрытых программ. Менеджер ищет папку Logs рядом с EXE или внутри выбранной папки.

Нажми «Собрать логи», выбери все логи, сегодняшнюю дату или несколько папок дат и укажи путь для ZIP. «Отменить сбор» останавливает текущую операцию.

<a id="section-17"></a>

## .NET: обновление установщиков

Открой «Проверить обновления .NET» из менеджера библиотек. «Проверить версии в сети» получает метаданные Microsoft и не устанавливает компоненты Windows. Сравни версии в папке и в сети, отметь нужные строки либо используй «Выбрать всё». Повторное действие «Снять выбор» очищает отметки.

«Обновить выбранные» скачивает установщики в выбранную библиотеку. Новая копия проверяется по SHA-512, цифровой подписи Microsoft, версии, семейству Runtime/ASP.NET Core и разрядности. Загрузка идёт во временный файл. Проверенная копия сохраняется до удаления старой. Если старый файл изменён или занят, он остаётся с предупреждением. При ошибке или отмене старый установщик сохраняется. Framework и произвольные установщики этим окном не обновляются; версии выбираются по соответствующей ветке/каналу, x86 и x64 проверяются отдельно.

Окончание загрузки не означает обновление .NET в Windows. Для установки вернись в менеджер библиотек, повтори проверку и отдельно подтверди действие. Закрытие во время загрузки запускает отмену; окно закрывается после её завершения.

<a id="section-6"></a>

## Библиотеки: действия и отмена

«По рекомендации» обновляет подходящий компонент без предварительного удаления. «Переустановить» явно удаляет выбранные зарегистрированные продукты соответствующего поколения и разрядности, затем запускает пакет комплекта. «Удалить» использует зарегистрированные деинсталляторы. Если надёжного способа удаления нет, действие останавливается.

Перед подтверждением проверь очередь и предупреждения. Сортировка таблицы не меняет порядок зависимостей. При ошибке, требовании перезагрузки или неподтверждённом результате очередь останавливается.

### Отмена

Нажми «Отменить операцию» и прочитай предупреждение. После подтверждения новые пакеты не запускаются; менеджер завершает процессы собственного задания. Общая служба Windows Installer и чужие установщики не завершаются. При закрытии во время активной операции также требуется подтверждение.

Принудительное прерывание не гарантирует откат. Системная часть Windows Installer может продолжить завершение операции или откат. После отмены дождись завершения системной операции и повтори проверку компонентов. Не запускай параллельно другую установку для исправления ещё незавершённой.

Подпись основной кнопки зависит от выбранных строк: «Установить выбранные», «Обновить выбранные», «Действия с выбранными» или «Проверить выбранные». При выборе установленных компонентов появляется окно «Действие с компонентами» с вариантами «По рекомендации», «Переустановить», «Удалить» и «Отмена». Без отметок действие может относиться к выделенной строке — перед подтверждением проверь список. После требования перезагрузки выбор оставшихся компонентов сохраняется, но автоматически очередь не возобновляется.

<a id="section-7"></a>

## Первичные системные настройки

Шесть групп: политика паролей системы Windows, контроль учётных записей, брандмауэр Windows, SmartScreen, права папок DataKrat и Bars, сенсорный режим КСО. Каждую группу применяй отдельно. При открытии выполняется проверка. Изменения — только после нажатия кнопки и подтверждения.

«Часовой пояс» и «Применить обои» доступны во время проверки настроек. Для обоев выбери «КСО» или «КАССА». Менеджер берёт изображение из соответствующей подпапки _wallpers. В текущем сеансе обои меняются сразу, другие профили получают их при входе в Windows.

Профиль BARS повторяет согласованный список политик. «Вернуть стандартные политики» применяет стандартные значения, а не прежние настройки компьютера. Существующие пароли и состав группы администраторов не меняются. Параметры, отсутствующие в этой версии Windows, пропускаются с сообщением. На контроллере домена локальный профиль паролей не применяется; доменные политики имеют приоритет.

После изменения UAC нужна перезагрузка. Если требуется перезагрузка, менеджер сообщает об этом в журнале. Брандмауэр переключается для доменного, частного и общедоступного профилей. SmartScreen для приложений отключается отдельной кнопкой для всех пользователей; «Вернуть стандартные политики» возвращает режим предупреждений. Уже открытое предупреждение нужно закрыть и запустить приложение заново. Политики организации имеют приоритет. Результат проверяется по фактическому состоянию; блокировка не считается успехом.

Выбери строку нужной группы: подписи двух действий меняются. Для брандмауэра это «Отключить все профили» / «Включить все профили». Для прав папок — «Выдать полный доступ» / «Проверить папки». Перед выдачей менеджер показывает найденные службы, чьи файлы могут стать доступны на запись, и пути к ним. «Проверить папки» только читает текущие разрешения. Для КСО — «Применить настройки КСО» / «Вернуть прежние настройки»: возврат использует сохранённую копию и доступен при её наличии. Это исключение из общего возврата стандартных политик. Действие ограничений КСО зависит от редакции Windows; неподтверждённая поддержка отражается в результате. «Проверить настройки» повторно читает состояния без применения профиля. Во время применения дождись завершения; закрытие окна не должно прерывать обслуживание Windows.

## Компоненты Windows

Открой менеджер библиотек и нажми «Компоненты». В отдельном окне показаны профиль IIS и компоненты Telnet/TFTP. При открытии состояние Windows проверяется автоматически.

2. Отметь нужные компоненты.
3. Проверь подпись действия: установка, удаление или оба действия.
4. Подтверди операцию и дождись окончания.

Изменения выполняются средствами Windows без автоматической перезагрузки. Если система требует перезагрузку, сохрани работу и запланируй её. Отдельная кнопка «Перезагрузка» находится в менеджере библиотек; сначала прочитай подтверждение.

Обслуживание Windows нельзя безопасно прервать закрытием окна: дождись завершения. Если Windows запросит источник файлов или сообщит об ошибке, используй её сообщение для диагностики. «Назад» возвращает в менеджер библиотек.

<a id="section-9"></a>

## Программы: установка и обновление

Поддерживаются Google Chrome, Notepad++, 7-Zip, AnyDesk и RuDesktop. При открытии выполняется локальная проверка: установщики автоматически не скачиваются.

1. Выбери корень комплекта или папку _soft.
2. Проверь пять строк программ: версию в Windows и доступный пакет.
3. Для получения свежих сведений из интернета нажми «Проверить версии в сети». Эта кнопка получает метаданные и не скачивает установщики.
4. Отметь программы и запусти установку или обновление. Та же или более новая установленная версия не предлагается как обновление старым пакетом.

Если подходящего локального пакета нет, установщик загружается при установке/обновлении с официального источника. Новый файл проверяется и сохраняется прямо в _soft выбранного комплекта. Если _soft отсутствует, она создаётся при загрузке. При недоступной для записи папке выбери доступный источник.

После сохранения нового пакета удаляются только распознанные старые установщики той же программы и разрядности. Посторонние и более новые файлы сохраняются. Скачанные установщики остаются в _soft для других компьютеров. Не изменяй пакет после проверки: неподтверждённый файл запускаться не должен.

Отметка переключается нажатием по строке, повторное нажатие снимает её. Свайп прокручивает список. После проверки подходящие отсутствующие или устаревшие программы могут быть отмечены автоматически — проверь выбор перед «Установить». Для остановки используй «Отменить» и прочитай предупреждение; после прерывания повторно проверь состояние программ.

## SQL Server и SSMS

В модуле «Установка программ» нажми **«SQL Server и SQL Server Management Studio»**. Менеджер читает наборы в `_soft\_SQL` и показывает установленные версии. Кнопка **«Скачать наборы…»** открывает загрузчик с выбранным разделом SQL.

Выбери шаг и нажми **«Запустить мастер установки»**. Для Express сначала запускай основной установщик, затем обновление. Для ISO менеджер подключает образ и открывает `setup.exe`. Настройки выбираются в мастере Microsoft.

Для автономного SSMS выбери ZIP и нажми **«Распаковать комплект»**. Затем выбери распакованный установщик. Если он не распознан, добавь его в набор кнопкой **«Подготовить набор…»**.

**«Подготовить набор…»** создаёт `package.json` с выбранными файлами в порядке добавления. Чтобы распространить манифест, загрузи его рядом с установщиками в папку набора.

## Программы: доступ и удаление

Для AnyDesk и RuDesktop можно настроить неконтролируемый доступ при установке либо отдельно для уже установленного клиента. Нажми «Настроить удалённый доступ» для выбранного установленного клиента либо включи настройку доступа перед «Установить». Введи пароль дважды: от 8 до 128 символов; значения должны совпадать. Поля при открытии пустые. Менеджер не запоминает пароль удалённого доступа. Кнопки с глазом показывают или скрывают пароль. Caps Lock предупреждает о регистре, а РУС или ENG под полем подтверждения показывает текущую раскладку. Во время настройки RuDesktop локальный администратор может увидеть пароль в параметрах запуска. Пароль AnyDesk не сохраняется в журнале менеджера.

Код 9010 означает, что служба программы удалённого доступа не запущена. Запусти клиент и проверь его службу в Windows. Код 9011 означает, что клиент отклонил пароль. Возможно, такой пароль уже задан. Проверь подключение с текущим паролем или задай другой.

Наличие установленной программы и её пароля не гарантирует сетевую доступность: проверь подключение с другого компьютера. Настройка доступа может зависеть от версии и правил самого клиента.

Кнопка «Приложения по умолчанию» открывает настройки Windows. Выбери нужные приложения там; менеджер ассоциации файлов и браузер по умолчанию не назначает.

### Удаление

Выбери нужные программы и действие удаления. Прочитай подтверждение: удаление может очищать настройки текущего пользователя и известные общие/служебные настройки. Другие профили пользователей не очищаются. Перед удалением Notepad++ сохрани важные несохранённые документы; резервные документы не заменяют собственную копию.

Отмена и выход во время операции требуют подтверждения. Прерывание стороннего установщика не гарантирует откат: проверь результат заново.

## Утилиты: установка и удаление

Модуль показывает локальные и доступные в облаке наборы утилит. Для распознанных программ, включая TurboWriter, WinSCP, Termite, R-Tool, MfgTool2, Piglet и fiLinn, можно создать ярлыки с иконками из EXE.

1. Укажи папку комплекта. Для загрузки выбери облако и нажми «Проверить в сети». Левая галочка выбирает набор для скачивания или распаковки. Все действия доступны в одном окне. Поддерживаются папки и обычные ZIP. При повторной распаковке ZIP ранее распакованная папка набора заменяется автоматически после успешного извлечения файлов.
2. В поле «Путь распаковки» укажи назначение.
3. В таблице наборов отметь «Ярлык» у нужных утилит. Если в наборе несколько подходящих EXE, нажми на название набора, чтобы раскрыть версии, и отметь нужные версии и ярлыки. Иконка берётся из выбранного EXE.
4. Нажми «Распаковать» и дождись результата. Для остановки копирования используй «Отменить».

Если локальный ZIP не читается, таблица помечает его как повреждённый. Проверь исправную копию в облаке. Если источник недоступен, неполон или скачивание не подтвердилось, менеджер может предложить другое облако. Загрузка сверяет файл с контрольной суммой источника перед заменой.

Это копирование файлов утилит. Для четырёх распознанных EXE настраивается запуск от администратора для текущего пользователя; сами EXE не редактируются.

При удалении проверь путь и подтверждение. Менеджер удаляет только распознанные каталоги утилит и относящиеся к ним ярлыки. Не указывай папку с важными посторонними данными. Если каталог не распознан, не пытайся обойти проверку переименованием файлов — сначала проверь выбранный путь.

Укажи полный путь к папке назначения _tools; при выборе родительской папки она добавляется автоматически. Распаковка сохраняет существующие настройки, а временная копия прежней папки удаляется после успешной записи. Копирование, настройка запуска от администратора и ярлыки — отдельные задачи прогресса. Сами утилиты после распаковки автоматически не запускаются. Кнопка «Удалить» требует подтверждения конкретного пути и распознанного состава; исходный комплект и посторонние файлы удаляться не должны.

<a id="section-12"></a>

## Реальный отклик службы и Swagger

Кнопка «Диагностика» открывает проверку отклика. Если выбран EXE, используется уже работающий процесс по точному пути файла; регистрация службы Windows не обязательна. Иначе проверяется выбранная строка службы. Без выбора предлагается выбрать EXE. Программа не запускает его автоматически и не выбирает наугад из нескольких процессов с одним путём.

Адрес определяется по портам процесса, настройкам размещения и очередям HTTP.sys. Перед повторным опросом автоматически найденного адреса его принадлежность проверяется снова. Если адрес не найден, прочитай журнал: процесс может ещё не открыть порт.

Поле адреса можно редактировать: укажи локальный HTTP/HTTPS-адрес безопасной диагностики или tcp://127.0.0.1:порт/. Для ручного адреса принадлежность выбранной службе не подтверждается; об этом написано в журнале. HTTP использует GET без автоматического перехода по перенаправлениям; TCP только устанавливает соединение без команд. Не вводи адрес бизнес-операции или пароль в URL. Во время запроса поле временно недоступно. «Проверить отклик» выполняет разовую проверку; тумблер включает повтор каждые 10 секунд до закрытия окна.

TCP подтверждает только приём соединения, а не исправность API или оборудования. Для Banking проверяется Ping с ожидаемым Pong. HTTP 401/403 означает, что сервер отвечает и требует доступа; 404 — адрес не найден; 405 — GET не поддерживается. Тайм-аут не доказывает зависание. Автоматического перезапуска нет.

Swagger — описание API, а не проверка всех функций. Программа ищет страницу по известным вариантам пути, включая /swagger/index.html и /index.html, и проверяет HTML. «Открыть Swagger» доступно при обнаружении страницы и открывает её в браузере. Редактирование адреса не меняет найденный Swagger. Его отсутствие не является ошибкой: он может быть отключён или размещён по нестандартному пути.

В Swagger сначала прочитай назначение метода, параметры и авторизацию. Названия health, ready, live, ping и status — только подсказки. Не запускай неизвестные команды через «Try it out». Даже GET может изменять данные. Проверка отклика не заменяет собственные журналы и проверку оборудования. Не все службы, конфигурации, дочерние процессы и нестандартные маршруты подтверждены реальными испытаниями.

<a id="section-13"></a>

## Поиск по инструкции

Поле «Поиск по всей инструкции» ищет фразу в названиях и полном тексте разделов без учёта регистра. Слева остаются только разделы с совпадениями. Справа показан выбранный раздел, найденные фрагменты подсвечены.

«Далее» и «Назад» переходят между всеми совпадениями, в том числе в других разделах. После последнего совпадения поиск продолжается с первого. Счётчик показывает номер текущего совпадения и общее количество.

Ctrl+F переводит курсор в поиск. F3 ищет следующее совпадение, Shift+F3 — предыдущее. «Сбросить» очищает запрос и возвращает все разделы. Текст справа можно выделить и скопировать сочетанием Ctrl+C. Размер окна можно менять; длинные разделы прокручиваются.

Инструкция встроена в EXE и доступна без интернета. Закрой окно кнопкой «Закрыть» для возврата в лаунчер.

В светлой теме выбранный раздел отмечен тёмно-зелёным фоном с белым текстом. Пустая область списка сохраняет фон окна. Список разделов слева и текст справа прокручиваются колесом и сенсорным свайпом. Свайп прокручивает, короткое касание выбирает раздел; прокрутка не меняет выбранный пункт. Выбор остаётся видимым при переходе к чтению текста.

## Папка комплекта BARS

Папка по умолчанию — `C:\BarsManager3000`. В ней рядом находятся `_libraries` (включая `Microsoft .NET`), `_soft`, `_tools` и `_wallpers`. В первичных настройках кнопка «Применить обои» открывает выбор «КСО» или «КАССА». Каждое нажатие выбирает другое изображение из соответствующей папки, пока набор не исчерпан. Обои применяются сразу в текущем сеансе. Другие существующие и новые локальные профили получат их при входе в Windows. Папка `_soft\_SQL` не участвует в автоматической установке программ.
