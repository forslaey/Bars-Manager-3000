# 2.3.67 — исправление окна диагностики

Тумблер рассчитан по реальной ширине текста и DPI: окончание «с.» выровнено по правой рамке журнала. Поле адреса ограничено видимыми краями карточки. Адрес редактируется, на время запроса поле блокируется.

Автораспознавание по точному пути EXE или SCM-службе сохранено. Найденный адрес повторно проверяется на принадлежность процессу. Ручной локальный HTTP/HTTPS/TCP-адрес используется при проверке с явным сообщением в журнале, что принадлежность не подтверждена. Ограничения протоколов ServiceProbe сохранены. Swagger по-прежнему относится к автоматически найденной странице. Ничего автоматически не запускается и не перезапускается.

Встроенная инструкция актуализирована: два режима диагностики, HTTP.sys, ручной адрес, HTTP/TCP и ограничения результата, поиск Swagger, отсутствие Swagger как нормальная ситуация. Добавлен раздел о загрузке, сравнении файлов и докачке из другого облака. Остальные разделы просмотрены.

Проверки: 10 утверждений UI диагностики; 451 проверки инструкции/поиска/UI (обе темы, моделирование 100/125/150/200%); 11 HTTP; 7 TCP. Реальное окно просмотрено в обеих темах на рабочем DPI, ручное редактирование подтверждено через UI. Полный Test.ps1, физический touch и новый аудит реальных служб не выполнялись. Сборка Framework 4.8 без подписи, публикация не выполнялась. Preview остаются в игнорируемой work.
