# Локальная версия 2.3.22 — 23.10.2026

Исправлен тумблер автообновления служб: отдельный контейнер, выравнивание по правому краю кнопки «Открыть службы», измерение текста и ограничение высоты. Проверены разворачивание, восстановление, обе темы и изменения размеров.

Ассоциации исправлены для всего профиля, а не только SVG:
- Chrome использует штатные зарегистрированные обработчики разных файлов и протоколов (ChromeHTML, ChromePDF и др.).
- Политика входа BARS.xml содержит только выбранные профили. Полный профиль для DISM хранится отдельно в ImageDefaults.xml; посторонние типы не включаются в политику.
- Повторное применение не возвращает снятые профили в политику. Исходный экспорт сохраняется до изменений.
- При удалении нельзя импортировать сокращённую политику как полный профиль Windows; если полного снимка нет, он сначала экспортируется.
- UserChoice и его Hash не подделываются и не удаляются. Для текущего сеанса требуется подтверждение Windows либо следующий вход на поддерживаемой редакции. Home требует ручного подтверждения.

Chrome — первая галочка, включена по умолчанию; две другие выключены. Кнопки: «Проверить версии в сети», «Применить ассоциации», «Настроить удалённый доступ». Описания официальных сайтов заменены по запросу; GitHub оставлен.

Проверки: AssociationProfileTests 10, RequestedUi2322Tests 35, SoftwareConfirmationTests 27, LayoutFitTests 1676, SoftwareTests 409, HeaderStyleTests 122, ResponsiveLayoutTests 5224. Это целевые проверки, не полный Test.ps1. Рабочий стол 125%; дополнительные масштабы в тестах имитируются, перенос между мониторами физически не проверен.

VM BARS-Test-W11: реальные установки Chrome, Notepad++, 7-Zip, повтор профиля всех трёх, профиль только Chrome (23 записи вместо 74), затем всех трёх и штатная перезагрузка/вход. В загруженном пользовательском реестре подтверждены SVG/HTML -> ChromeHTML, PDF -> ChromePDF, TXT/CFG/JSON/CONFIG -> BARS.NotepadPlusPlus.Text, ZIP/7Z/RAR -> BARS.SevenZip.Archive. Это проверка фактических назначений, не визуальный запуск каждого файла. Снимок Before-Associations2322-20261023115342 восстановлен, VM выключена. Хост не менялся.

Общий механизм имел ошибки; конкретный SVG на хосте также имел осиротевший UserChoice Applications\\xnviewmp.exe без зарегистрированного обработчика. Одна иконка не доказывает действующее назначение. Не утверждаем, что менеджер создал именно этот осиротевший выбор.
