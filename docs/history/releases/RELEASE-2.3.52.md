# 2.3.52 — согласованные области таблиц и прокрутки

Без подписи, .NET Framework 4.6. Сетевой/установочный функционал не менялся.

Общая LibraryGridScrollBar теперь обновляет видимость после изменения списка, высоты строк, ширины столбцов, размера и привязки данных. Если строки помещаются, полоса скрывается и таблица получает освободившуюся ширину. Фон непосредственного контейнера/полосы согласован с BackgroundColor таблицы. Начало бегунка расположено под шапкой. Исправление распространяется на службы, библиотеки, первичные настройки, обновления .NET и результаты комплекта. У программ сохранён свой детерминированный FitRows (AutoHideWhenUnused=false), чтобы не конфликтовать с подсчётом переносов строк. Панели равных кнопок не резервируют место под скрытую полосу. Существующие индивидуальные отступы заголовков не унифицировались.

Проверки: GridViewportTests 204 (0/1/80/2/0/100/1 строк, две темы, моделирование 100/125/150/200%, шесть реальных preview-окон), LibraryManager 155, Software 336, Navigation 167, UtilityModule 583, BundlePolish 17, BundleUiRevision 29, UserGuide 475, TouchGrid 39, ToolsCompact 32, метаданные команд 39 — 2076 утверждений, все прошли. Снимки шести табличных окон сохранены; просмотрены результаты .NET и библиотек. Прокрутка длинного списка и переход к короткому проверены на макетах без системных операций.

Полный Test.ps1 не запускался; все физические мониторы/КСО не испытаны. Изменения относятся к таблицам и их полосам, не ко всем произвольным текстовым/списочным контейнерам приложения. Сетевые загрузки, установки, реальные операции служб и изменения C:\Библиотеки не выполнялись. Прежние ограничения Google web adapter/Base64/Ui2330 сохраняются.
