# BARS Manager 3000 2.0.1 — 19.10.2026

Обновлён интерфейс обоих модулей и лаунчера:
- Подписи тумблеров: «Проверять каждый 10с.» и «Проверять каждый 30с.».
- В библиотеки добавлена кнопка «О программе», в службы — «В меню». При отдельном запуске модуля служб возврат открывает лаунчер в том же процессе.
- Текст лаунчера выровнен по левому краю; кнопки открытия модулей перенесены под описания, с отступом от нижней границы карточки.
- Таблицы имеют единообразные горизонтальные и вертикальные линии. Рисование круглой отметки сохраняет рамку и состояние графического контекста. Частичная перерисовка карточки ограничена обновляемой областью.
- Клик по всей ячейке первого столбца переключает выбор одним нажатием; область расширена до 46 логических пикселей. Пробел переключает выбранную строку. Неподходящие компоненты и выбор при установке/проверке заблокированы.

Полный Test.ps1 прошёл: 1682 проверок, включая 46 новых проверок ввода/отрисовки/навигации в обеих темах. Одна необязательная проверка символьных ссылок пропущена из-за отсутствия Windows-привилегии (1314). Снимки всех трёх окон в обеих темах просмотрены. Реальные установщики и операции управления службами не запускались.

Сборка и встроенные помощники нацелены на .NET Framework 4.6. Подпись не добавлялась, прежний signed EXE не изменён. Полная проверка реальной установки библиотек на чистых виртуальных машинах остаётся отдельным этапом.
Основной файл bin\Bars Service Manager 3000.exe был занят запущенным процессом, поэтому новый EXE сохранён как bin\Bars Manager 3000 2.0.1.exe. Старый файл при этой сборке не заменялся.
