# BARS Manager 3000 2.3.38

Выпуск без подписи. Архитектура выбранной службы и отдельные обновления установщиков .NET.

## Использование

- В службах при выборе файла кнопкой, перетаскивании или выборе зарегистрированной службы имя дополняется архитектурой: 32-/64-разрядная, AnyCPU, AnyCPU с предпочтением 32 бит или ARM64. Читаются заголовки PE/CLR, файл не запускается. Если файл недоступен или повреждён, это явно указано. Это архитектура файла, а не измерение работающего процесса по PID; зависимости AnyCPU могут ограничить фактический запуск.
- В библиотеках над таблицей появился фильтр «Все библиотеки» / «Microsoft .NET». Он не добавляет фиктивных строк в каталог. При переключении выбор очищается; «Выбрать всё» и «Выбрать недостающие» действуют только в видимой группе.
- «Обновления Microsoft .NET…» открывает отдельное тематическое окно. «Проверить версии в сети» получает только официальный JSON для веток, представленных в каталоге. Таблица отдельно показывает ветку/разрядность, версию в комплекте и в сети. Система Windows здесь не устанавливается и не меняется.
- Отметь нужные обновления и нажми «Обновить выбранные установщики». Папка Библиотеки запрашивается только при загрузке, если ещё не выбрана. Стабильные .NET Runtime и ASP.NET Core x86/x64 обновляются только внутри major.minor. Preview, Framework Developer Pack, SDK, Desktop Runtime и Hosting Bundle не подменяются. Более новая локальная версия не понижается.
- Загрузка идёт во временный файл рядом с будущим установщиком: проверяются SHA-512 Microsoft, WinVerifyTrust, подписант .NET/Microsoft Corporation с организацией Microsoft Corporation, метаданные семейства/версии/разрядности. Только затем новый файл публикуется; старый удаляется только при совпадении его прежнего SHA256. Занятый, изменённый или недоступный старый файл сохраняется с сообщением. Существующий файл новой версии не перезаписывается.
- Закрытие окна отменяет запрос/передачу и ожидает завершения очистки. При ошибке/отмене до публикации старый файл остаётся. После успешных загрузок закрой окно: основной каталог перечитывается, используются новые установщики. Автоматической установки в Windows нет.

## Проверки

RuntimeFeatureTests: 26 проверок PE/CLR, AnyCPU/x86/предпочтения 32 бит, native x64, повреждённого/недоступного файла; изоляция веток/архитектур/Preview, запрет неофициального адреса, интерфейс диалога, безопасный выбор фильтра. RuntimeDownloadTests отдельно (не включён в стандартный офлайн-набор) действительно загрузил четыре официальных пакета 8.0.33 в work: .NET и ASP.NET x86/x64; подтвердил SHA512, доверие подписи Windows, метаданные, сохранение и удаление тестового старого файла. Проверены существующее назначение, предварительная отмена, отмена во время передачи, неверный SHA512 и сохранность старого файла. Установщики не запускались. Выявленный в тесте официальный подписант CN=.NET учтён без ослабления проверки цепочки/организации.

Регрессии: Navigation 167, LibraryManager 155, LibraryCancellation 14 (только инертные процессы), InkAlignment 128, WindowSession 58, LayoutFit 1700, ResponsiveLayout 5304; Core 62, Management 72, ManagedStore 88, ReviewRegression 47, метаданные команд Windows 39. Обе темы, моделируемые 100/125/150/200%, обычные/портретные поверхности. Новые снимки просмотрены; первоначальный дефект высоты строки новой панели при 150% исправлен до выпуска.

.NET Framework 4.6, прежняя иконка и встроенные помощники x86/x64. Реальные установки/удаления компонентов, службы, политики и физический КСО не проверялись/не менялись. Полный Test.ps1 не объявляется прошедшим: прежние ограничения Base64/Ui2330 сохраняются. Загрузка не является гарантией совместимости пакета со всеми ОС; установка по-прежнему проходит через существующие проверки менеджера. Все новые загрузочные испытания ограничены work.

В начале работы уже отсутствовали старые releases/v2.3.30–v2.3.36. Эти пользовательские удаления не восстановлены, не добавлены в коммит и не публикуются. В GitHub Release только EXE, RELEASE-2.3.38.md и CHANGELOG.md.
