# BARS Manager 3000 — 2.3.6, 21.10.2026

- Утилиты: два одинаковых тонких поля для источника и назначения; уменьшение высоты сверху сохраняет нижнюю линию кнопки. Ширина рассчитана по подписи «Создать ярлыки на рабочем столе»; край рамки совпадает с концом подписи с погрешностью шрифтового отступа. Опция ярлыков опущена на 6 логических единиц. Кнопки выбора находятся рядом с полями.
- Программы: источник в таком же поле с соседней кнопкой выбора; убрана пустая полоса под четырьмя строками таблицы. Отдельные действия «Установить», «Удалить», «Настроить доступ». Установка доступна только для отсутствующей программы или подтверждённого обновления; совпадающая/более новая установленная версия не переустанавливается. Для уже установленного AnyDesk сетевой пакет сначала проверяется и определяется его версия: неизвестная версия не считается обновлением.
- Удаление Notepad++, 7-Zip, AnyDesk и RuDesktop использует штатный тихий деинсталлятор. Удаление подтверждается пользователем, действующая регистрация и расположение программы проверяются повторно. У MSI запрещена автоматическая перезагрузка. Если деинсталлятор вернул ошибку, нужна перезагрузка, регистрация осталась или процесс не завершился — очистка настроек не объявляется успешной.
- После подтверждённого удаления очищаются известные настройки текущего пользователя, общие настройки AnyDesk, служебная конфигурация RuDesktop и сохранённый менеджером пароль. Чужие профили Windows не обходятся и не очищаются. Резервные файлы несохранённых документов Notepad++ переносятся в UninstallBackups в каталоге данных менеджера, их путь записывается в журнал. Собственные регистрации ассоциаций удаляются; внешняя корпоративная политика не перезаписывается.
- «Настроить доступ» меняет постоянный пароль установленного AnyDesk/RuDesktop без запуска установщика. Протокол настройки сохранён: AnyDesk — стандартный ввод, RuDesktop — документированные параметры. Пользователь подтвердил работоспособность обоих протоколов на предыдущей сборке.
- В диалогах паролей справа размещены иконки приложений, извлечённые из установленных файлов и встроенные в менеджер. Добавлено второе скрытое поле «Подтверди пароль». Продолжение разрешено только для пароля 8–128 символов без управляющих символов и его точного совпадения с подтверждением, с учётом регистра и пробелов. При изменении первого поля подтверждение проверяется заново. Сохранённый пароль не заполняет второе поле автоматически.
- Службы: в верхней карточке появился заголовок «Менеджер служб»; инструкции, поле и выбор файла размещены ниже в отдельных строках.
- Компоненты Windows: проверка автоматически начинается при открытии окна. Без отмеченных строк подпись действия отражает состояние списка: «Удалить выбранные», если все установлены; «Установить и удалить» при смешанном составе. Сама кнопка без отметок остаётся выключенной.

Проверки: UtilityModuleTests 502, SoftwareTests 393, SoftwareMaintenanceTests 29, LayoutFitTests 1404, RapidSelectionTests 52, ToolsRemovalTests 18, ThemeTests 607, LibraryManagerTests 155, UiPolishTests 103. Всего 3263 утверждения; 10 foreground-проверок пропущены без активного лаунчера. Проверены обе темы и имитация геометрии 100/125/150/200%, немедленное переключение отметок, размеры полей/кнопок, несовпадающие и совпадающие пароли, доступность действий по установленной/доступной версии и удаление только собственных временных макетов настроек. Снимки изменённых окон и диалогов просмотрены. Физическое переключение DPI не проверялось.

Настоящие программы на рабочем компьютере не устанавливались и не удалялись, настройки доступа/ассоциации/компоненты Windows не менялись. Полное реальное удаление четырёх программ и матрица установщиков требуют отдельного этапа испытаний в VM; прохождение этих проверок не заменяет такие испытания.

Сборка: один `bin/Bars Manager 3000 2.3.6.exe`, без подписи, с фирменной иконкой и встроенными помощниками. Предыдущий файл сохранён в игнорируемом `work/previous-builds`. Изменения пока не опубликованы на GitHub.
