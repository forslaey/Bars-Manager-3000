# BARS Manager 3000 2.3.16

- В лаунчере четыре основные карточки 2×2 и широкая «Первичные системные настройки». Отдельное окно с двумя темами, журналом, автоматической проверкой состояния и подтверждением каждого изменения.
- Все 14 параметров UAC и восемь параметров паролей из согласованных скриншотов. Отмена профиля возвращает стандарт Windows, а не прежние значения. Для классических паролей используется whitelist значений заводского defltbase.inf. Новые параметры недоступных ОС пропускаются явно. Обычный пользователь не добавляется в администраторы, права SYSTEM/TrustedInstaller не выдаются. После политик паролей/UAC предлагается перезагрузка; автоматически не выполняется.
- Брандмауэр переключает Domain/Private/Public и проверяет действующий ActiveStore. Defender переключает только защиту в реальном времени; защиту от изменений не обходит. Отказ Windows не считается успехом.
- Google Chrome первым в списке программ. Официальный автономный Enterprise MSI x64, версии через Google VersionHistory API без скачивания при проверке. Существующие правила сохранения в выбранной _soft, проверки подписей/версий, отсутствия понижения и удаления старого файла после проверки сохранены. Поддерживается установка и удаление MSI Chrome.
- AnyDesk/RuDesktop: подтверждение пароля, отключённая по умолчанию галочка стандартного пароля BARS, два независимых глазика, Caps Lock с подсказкой, динамические РУС/ENG. Галочка блокирует оба поля и глазики, снятие возвращает ранее введённые значения. Запоминание остаётся отдельным выбором пользователя (DPAPI). Стандартный пароль пока присутствует в исходниках по согласованию; обфускация отложена.
- Изменена только согласованная фраза журнала проверки программ. Инструкция дополнена новым модулем.

## Проверки

Проверены реальные метаданные и цифровая подпись Google MSI 156.0.8078.48, соответствие официальному API. В выделенной Hyper-V VM: чтение всех настроек; применение и стандарт политик паролей, UAC, всех профилей брандмауэра; отказ отключения Defender при включённой Tamper Protection и подтверждение включённой защиты; установка Chrome, пропуск повторной установки, удаление. В ходе испытаний исправлено создание существующего раздела SAM и читаемость ошибок PowerShell. Реальное успешное отключение Defender при выключенной Tamper Protection не проверялось. Действие UAC после настоящей перезагрузки/нового интерактивного входа не проверялось; значения и требование перезагрузки подтверждены. VM возвращена к контрольной точке до испытаний и выключена; рабочие настройки хоста не менялись.

Проверки кода, макетов и регрессий описаны в DEVELOPMENT-STATE.md. Светлая и тёмная темы, реальный системный DPI 120, геометрическая имитация 100/125/150/200%. Это не полная матрица всех Windows/доменов/мониторов. Проверки библиотек с настоящими установщиками не выполнялись.

Сборка без подписи и без обфускации: bin/Bars Manager 3000 2.3.16.exe. Прежняя сборка архивируется в work/previous-builds. На GitHub этим этапом не публиковалось.

Подробные значения и источники Microsoft: SYSTEM-SETTINGS.md. MSXML x86/x64: MSXML6-ИССЛЕДОВАНИЕ.md.
