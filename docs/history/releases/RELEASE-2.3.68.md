# 2.3.68 — единый прогресс загрузок

Общий DownloadProgressView используется загрузкой комплекта, установкой программ и обновлением установщиков .NET. Фирменный зелёный градиент, плавное заполнение, процент справа над полосой, объём/скорость/оценка времени и имя файла ниже. Полное имя доступно при наведении. Блок масштабируется с DPI и наследует тему.

При неизвестном размере — движущийся сегмент без процентов. Проверка хеша/подписи, сохранение и установка показаны отдельными этапами; процент установки не выдумывается. 100% означает успешную проверку и сохранение. Пауза останавливает движение, скорость после продолжения измеряется заново. Отмена и ошибка не объявляются успехом. Системное отключение анимаций учитывается.

Транспорт программ и .NET сообщает структурированные данные по фактическим байтам; UI получает только последний снимок без очереди вызовов на каждый сетевой блок. Комплект показывает общий прогресс очереди и готовые файлы, скорость считает по сетевым байтам без сохранённого префикса. Повтор соединения сопровождается отсчётом и причиной. Проверки файлов и безопасная замена старых копий сохранены.

Комплект: клиентская область 650×680; журнал сохранён, при малой поверхности прокручивается содержимое, нижние действия закреплены. Программы: начальная область 1120×880, адаптивная компоновка сохраняет журнал, прогресс и навигацию. .NET: отдельная полоса под таблицей по её правому краю; кнопка «Обновить выбранные» помещается в строку. Встроенная инструкция обновлена.

## Проверки

- DownloadProgressTests: 299 утверждений в итоговом прогоне (число событий сетевой передачи может меняться): известная/неизвестная длина HTTP, обрыв, лимит, отмена; движение, отсутствие переполнения, пауза, завершение после проверки; все три модуля, две темы, моделируемые 100/125/150/200%, малая высота, читаемость журнала и видимость навигации.
- Реально скачаны официальный 7-Zip 26.05 (1 663 506 байт) и .NET Runtime 8.0.33 x64 (28 613 992 байт). Проверены реальные счётчики, этапы проверки/сохранения, подписи и метаданные, SHA-512 .NET. Проверены отмена обоих транспортов и неверный SHA-512: прежние файлы сохранены, успешное завершение не выдано.
- BundleTransportTests: 39 проверок локального HTTP: полная загрузка, Range/продолжение, игнорирование Range, повтор, короткий ответ и неверный хеш.
- SoftwareTests 336; SoftwareMaintenanceTests 32; SoftwareStorageTests 27; BundleTests 29; BundleUpdateTests 18; DotNetPresentationTests 101; DotNetWholeRowsTests 24; DotNetViewportBottomTests 32; UserGuideTests 451; BundleUiRevisionTests 29. BundleFailureTests 29 (ошибки публикации/носителя/доступа и сохранение прежних файлов).
- Реальные окна всех трёх модулей просмотрены в обеих темах. Последовательные кадры демонстрационного потока подтверждают изменение заполнения и процентов. Функциональные реальные скачивания выполнены отдельно через рабочие транспорты; это не установка программ через UI.
