# 2.3.58 — компактные результаты и компоненты Windows

В результатах сверки удалены отдельный заголовок над таблицей и переключатель темы; текущая тема приложения сохранена. Таблица получила дополнительную высоту. Длинные названия переносятся, три равные кнопки выбора сохранены. Внешний scrollbar ограничен фактической высотой таблицы, не контейнера. Свайп ServiceGrid сохранён.

В распаковке утилит переключатель темы скрыт. Компоненты Windows уменьшены до 650×500 базовых единиц, строки чекбоксов и карточки имеют фиксированные компактные интервалы; действия компонентов не менялись.

48 проверок результатов (две темы, длинные названия), 4 проверки окон/темы, 583 проверки утилит, 11 зеркал и 39 метаданных команд прошли. Снимки тёмного окна результатов с длинными названиями и компонентов Windows просмотрены. Реальные установки, сетевые загрузки и физический touch не выполнялись. Полный Test.ps1 не запускался; прежние ограничения общих UI-тестов/Base64/Ui2330 не объявляются исправленными. Без подписи, .NET Framework 4.6.
