# 2.3.42 — загрузка комплекта с Яндекс Диска

Добавлено окно загрузки и сверки папки «Библиотеки» с постоянной публичной ссылкой владельца комплекта. Открывается из главного меню, библиотек и программ; при отсутствии локального источника предлагается загрузка. Проверка получает метаданные и считает локальные SHA-256 без запуска установщиков.

Выбор разделов: библиотеки/.NET, программы, утилиты. Выбор отдельной строки кликом или касанием; свайп прокручивает. Очередь 1–4 параллельных файлов, прогресс активных файлов и общий, скорость/оценка времени, пауза, продолжение и отмена. Частичные файлы сохраняются в .bars-download, привязаны к пути и SHA-256. Продолжение использует Range, при игнорировании Range текущий файл начинается заново. Временные сетевые ошибки повторяются с ожиданием.

Готовый файл публикуется только после размера/SHA-256. Неизвестные отличающиеся файлы, настройки и дерево утилит защищены. Обновление существующего EXE возможно лишь по квитанции предыдущей загрузки, при неизменённой локальной копии и сравнимой версии без понижения. Отличающиеся MSI автоматически не заменяются. Переименованные версии скачиваются как новые файлы; старые не удаляются. Установщики никогда не запускаются загрузчиком.

Включены накопленные локальные правки: выбор всей строкой в библиотеках, программах и обновлениях .NET; сенсорная прокрутка текстовых журналов и инструкции; компоновка окна действия с компонентами и выравнивание отметки удалённого доступа.

Проверки: BundleTests 22; BundleTransportTests 16 (локальный HTTP-сервер: полная передача, Range, игнорирование Range, 503, плохой хеш); NavigationTests 167; SoftwareConfirmationTests 18; TouchGridTests 39; LibraryManagerTests 155; SoftwareTests 336; UserGuideTests 475; TouchTextTests 11; метаданные команд 39. Реально прочитано дерево Яндекс Диска (187 файлов), скачан и проверен только !ПОЯСНЕНИЕ.txt (996 байт).

Ограничения: полный комплект 1,36 ГиБ не скачивался; физический сенсорный экран, аппаратная инерция, все флешки/файловые системы и визуальная матрица нового окна не проверены. Полный Test.ps1 не объявляется прошедшим; прежние ограничения Base64/Ui2330 не исправлялись. Частичные файлы сохраняются при отмене, кнопки удаления недокачанного пока нет. Параллельность задаётся вручную, автоматического уменьшения нет. Оценка времени приблизительная. SHA-256 из API подтверждает совпадение с источником, не заменяет проверку доверия издателя. Каталог программ BARS не реализован.

Сборка без цифровой подписи, .NET Framework 4.6.
