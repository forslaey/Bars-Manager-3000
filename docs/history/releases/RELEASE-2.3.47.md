# 2.3.47 — таблица результатов, темы и полный Google-прогон

Без подписи, .NET Framework 4.6.

## Интерфейс
- Результаты: FullRowSelect, выбор всей строкой и клавишей Space, сглаженные DPI-зависимые круглые отметки, фирменная полоса прокрутки LibraryGridScrollBar и TouchGrid для свайпа. Заголовок и viewport имеют общий левый край без дополнительных Margin; шапка таблицы центрирована, рамки/выделение/цвета согласованы с остальными модулями в обеих темах.
- При нуле отличий результат не открывается, кнопка «Результаты» выключена. При наличии отличий автоматический показ и повторное открытие сохранены.
- Увеличены промежутки вокруг вертикального выбора разделов, между журналом, пояснением и прогрессом. Фиксированное окно 650×550; выбор облака уменьшен до 420×250 с фиксированной высотой области переключателей.
- Исправлено общее применение темы к BrandCheckBox: палитра теперь обновляется вместе с базовым деревом элементов, в светлой теме подписи облаков больше не исчезают.

## Сеть и прогресс
- Google: предварительное получение ссылки запрашивает только bytes=0-0 вместо начала полного файла; ограничен размер HTML подтверждения, выделен проверяемый парсер с запретом чужого хоста и корректным кодированием параметров.
- Обход независимых папок Google пакетами до 4 запросов, с HTTP gzip/deflate и лимитом соединений 6. Валидация путей/дубликатов/неполного листинга сохранена. Новая локальная сверка всё равно читает содержимое, хеш-кэш по времени не используется.
- Начало передачи допускает до 90 секунд ожидания, чтение — 30 секунд; отмена действует и на подготовку облака перед скачиванием. Убран доступ к CheckBox из фонового потока: выбор разделов снимается на UI-потоке.
- Полученный полный part не означает готовность: 100% выдаётся только после SHA-256 и публикации. Общий прогресс ограничен ниже 100 до завершения всех выбранных файлов; сетевые байты не включают сохранённый префикс. После паузы сбрасывается интервал скорости.

Целевые наборы из итоговых исходников прошли: Polish 17, Mirror 9, UI revision 29, Layout 56, Failure 29, Update 18, Bundle 29, Transport 39, Storage 27, Software 336, Navigation 167, Confirmation 18, TouchGrid 39, LibraryManager 155, UtilityModule 583, UserGuide 475, TouchText 11, метаданные 39 — 2076 утверждений. Просмотрены реальные снимки результатов и компактного выбора облака в обеих темах. Transport проверяет отсутствие 100% до публикации и точное количество сетевых байтов для Range/игнорирования Range/короткой передачи.

Полная загрузка Google без обращения к Яндексу: **180/180 файлов, 1 126 691 084 байта, 0 ошибок в итоговом прогоне**. Все размеры/SHA-256 проверены. Первая полная попытка дала 179/180 (таймаут Developer Pack); после исправления таймаутов/получения ссылки и повторного запуска оставшийся файл скачан, готовые 179 перепроверены по хешу. Итоговый повтор занял 215,7 с, включая повторную сверку и недостающее скачивание; это не скорость холодной загрузки всего комплекта. Тестовые копии только в work, ни один скачанный файл не запускался. Три неизвестных desktop.ini исключены из 180 подтверждённых файлов, программы _soft по требованиям вне загрузчика.

## Ограничения
Полный Test.ps1 не объявляется успешным; физический КСО/инерция и все мониторы не испытаны. Google по-прежнему использует публичный веб-листинг и встроенный каталог хешей (не официальный API, неизвестная пагинация отклоняется); контрольный каталог не обновляется автоматически в режиме только Google. Не обещается устранение всех возможных сетевых сбоев/квот. Реальный failover между облаками не испытывался из-за проблем Яндекса. C:\Библиотеки не менялась, каталог BARS вне спринта. Ограничения Base64/Ui2330 сохранены.
