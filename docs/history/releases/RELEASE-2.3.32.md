# BARS Manager 3000 2.3.32 — компактное управление и растущий журнал

27.10.2026. Программа и оба встроенных помощника без цифровой подписи. [Релиз](https://github.com/forslaey/Bars-Manager-3000/releases/tag/v2.3.32).

## Интерфейс

- В установке программ пять строк таблицы, опция удалённого доступа и кнопки образуют компактную группу сверху. Чекбоксы больше не центрируются в растянутой процентной области. Всю дополнительную высоту занимает журнал; статус и «В меню» закреплены снизу.
- В первичных настройках список ограничен фактической высотой строк, кнопки следуют за ним, свободная высота отдана журналу. На коротком экране таблица сохраняет прокрутку, при недостатке места рабочая группа может прокручиваться отдельно от журнала и навигации.
- Общий CompactJournalLayout рассчитывает высоты по измеренным строкам и масштабированным фиксированным элементам. На портретном экране журнал растёт, а управляющие элементы не разъезжаются. В обычном окне 1280×920 проверено размещение всех пяти программ; полезный минимум журнала сохранён.
- Окно компонентов Windows ограничено компактной рабочей областью 760×590 базовых единиц, аналогично распаковке утилит. На большом экране карточки не вытягиваются во всю высоту.
- В службах сохраняется расширение журнала, в библиотеках — списка компонентов, в инструкции — текста. Лаунчер и утилиты сохраняют компактную область. Эти разные назначения свободного места проверены отдельно; повсеместное растягивание журнала не вводилось.

## Ассоциации

По прямой просьбе пользователя удалено автоматическое назначение Chrome браузером и ассоциаций Notepad++/7-Zip. Убраны обе галочки, применение после установки, привилегированная команда software-defaults, DISM/XML-профили, регистрация обработчиков BARS и вмешательство в ассоциации при удалении программ. Устаревшие тесты и VM-сценарий этой удалённой функции исключены; остальные проверки установки и удаления сохранены.

Кнопка «Приложения по умолчанию» только открывает штатную страницу Windows для самостоятельного выбора. Она не изменяет реестр, политики или выбор пользователя. Описания карточки и соответствующий абзац инструкции обновлены; остальные пользовательские формулировки сохранены. Настройка постоянных паролей AnyDesk/RuDesktop остаётся.

Очистка/откат старых ассоциаций тестовых стендов не выполнялись и не добавлялись по последнему указанию пользователя. Существующие профили прежних выпусков не перенастраиваются. Штатные установщики программ продолжают собственную регистрацию и удаление; менеджер принудительные назначения больше не выполняет.

## Проверки и границы

Ui2332Tests: 533 проверки обеих тем и имитации 100/125/150/200%, нативного разворачивания/восстановления и независимых от размеров физического монитора поверхностей компоновки 1366×768, 1920×1080, 1080×1920, 1440×2560. Проверены отсутствие промежутков между таблицей/опцией/кнопками, рост журнала, навигация, доступность строк и назначение свободного места в других модулях. Просмотрены портретные и горизонтальные снимки.

Дополнительно прошли: LayoutFitTests 1684, SoftwareTests 336, SoftwareConfirmationTests 18, SystemSettingsRegressionTests 100, UtilityModuleTests 558, SoftwareMaintenanceTests 32, UserGuideTests 459, Ui2324Tests 287, KioskTouchTests 204 (без пропусков), RequestedUi2322Tests 31, Ui2323Tests 81, Ui2329Tests 3688; Core 62, Management 72, ManagedStore 88. Изменённые ожидания старых тестов касаются только удалённых опций и новой безопасной кнопки.

Реальные установки/удаления, применение политик, изменение ассоциаций хоста, перезагрузка и VM не выполнялись. Проверки команд/очистки использовали макеты, временные файлы и инертные процессы. Наличие кнопки настроек проверялось без фактического открытия Settings. Физического КСО у пользователя сейчас нет: макеты не означают испытание настоящего сенсорного оборудования и всех физических DPI.

Полный Test.ps1 в этом проходе не запускался и не объявляется пройденным. Из 2.3.31 остаётся известная особенность старого Ui2330Tests: с действующим DPI-манифестом проверка равенства отступов служб не проходит и воспроизводится на прежних исходниках. Код служб и требования этого теста не менялись; для этой задачи добавлены проверки распределения высоты, которого в прежних тестах не было.

Релиз содержит ровно три вложения: EXE, этот RELEASE-2.3.32.md и CHANGELOG.md. ZIP и TXT-памятки не прикладываются; памятки остаются отдельно в исходниках. После подтверждения GitHub устаревшие промежуточные материалы work очищаются.
