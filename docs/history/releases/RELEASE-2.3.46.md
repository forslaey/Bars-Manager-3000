# 2.3.46 — компактный интерфейс, выбор файлов и Google-зеркало

Без подписи, .NET Framework 4.6.

- Основное окно загрузки фиксировано 650×500 базовых единиц, без растягивания/максимизации; два вертикальных переключателя, компактный журнал, поле папки и кнопки 3×2. Результаты открываются повторно отдельной кнопкой без новой проверки.
- Результат проверки фиксирован 650×350, без максимизации, с фирменными отметками выбора строк. Защищённые локальные файлы нельзя включить в замену. Выбор сохраняется при закрытии диалога.
- Лаунчер без максимизации; нижние кнопки расширены одинаково, «Скачать комплект» без переноса по размеру кнопки.
- Выбор облака перед проверкой: Яндекс, Google либо оба (предупреждение о длительности). Перед скачиванием — одно облако. При ошибках предлагается альтернативное; совпадение пути/размера/SHA-256 обязательно для продолжения.
- Google: рекурсивный публичный листинг и получение ссылки скачивания/формы подтверждения, отмена и повторы. Секреты/чужие API-ключи не используются. Для работы только с Google встроен проверенный каталог 187 путей/размеров/SHA-256 предыдущего комплекта. При проверке обоих источников применяется актуальный каталог Яндекса. Неизвестные файлы или отличающийся размер пропускаются с объяснением. SHA-256 содержимого Google подтверждается при скачивании, не по одному размеру.

Реальный Google-прогон: 180 файлов сопоставлены с каталогом; скачан только !ПОЯСНЕНИЕ.txt 996 байт, SHA-256 подтверждён, Яндекс не запрашивался. Три новых desktop.ini пропущены как неподтверждённые. Установщики не скачивались/не запускались в этом прогоне.

## Ограничения
Google использует публичный веб-листинг, НЕ официальный Drive API: изменение формата, квоты, вход/ограничения и неполный листинг приводят к явному отказу. Пагинация неизвестного веб-формата не реализована: неполный ответ отклоняется. Встроенный каталог не обновляется сам при режиме только Google; новые файлы требуют актуальной сверки Яндекса/обновления каталога. Обе облачные копии не объявляются побайтно одинаковыми лишь по листингу; контроль Google по SHA-256 после скачивания. Полный комплект Google, крупные формы подтверждения и реальный отказ с переходом между облаками пока не испытаны end-to-end. Поэтому не считать интеграцию Google полностью испытанным эквивалентом официального API Яндекса. Физические DPI/КСО позже; C:\Библиотеки не менялась. Каталог BARS вне спринта. Ограничения Base64/Ui2330 сохранены.
