# BARS Manager 3000 — 2.3.12, 21.10.2026

«Проверить версии» больше не скачивает AnyDesk для чтения номера из установщика. Версия Windows определяется из официального текстового [списка выпусков AnyDesk](https://download.anydesk.com/changelog.txt). Другие платформы и предварительные версии не принимаются. Если текст не распознан или источник недоступен, номер не угадывается и пакет ради проверки не скачивается. Получение метаданных допускает только текст/JSON и отклоняет бинарный ответ до чтения его содержимого.

Из RefreshPackages полностью удалён вызов Download. Загрузка установщиков осталась в действии установки. Перед ней повторно проверяется текущее состояние Windows: той же или более новой установленной версии пакет не нужен. Для отсутствующей программы разрешена установка, для установленной — только более новая версия. Если соответствующий проверенный пакет той же версии уже есть в _soft/кэше, используется он; для источников с опубликованным SHA-256 требуется совпадение хеша. Прежняя проверка скачанного файла по версии/подписи/доступному эталонному хешу сохранена.

По просьбе пользователя встроены новые AnyDesk.png и RuDesktop.png из assets. Имя переданного файла RuDesktop.png.png исправлено на RuDesktop.png. Встроенные ресурсы побайтно совпадают с новыми исходниками; просмотрены снимки диалогов пароля с обновлёнными иконками в обеих темах.

Проверки: SoftwareVersionCheckTests 51, SoftwareStartupTests 33, SoftwareTests 393, SoftwareMaintenanceTests 32. Регрессионная проверка использует установленный AnyDesk и успешные подставленные метаданные: неизвестная, совпадающая и более новая версия, обе темы, шесть явных проверок. HTTPS-перехватчик запрещает реальные запросы к пакетам; ни одного запроса загрузки не возникло. В отличие от проверки только ошибки сайта, этот сценарий покрывает прежнюю ветку загрузки при успешно полученном описании AnyDesk.
