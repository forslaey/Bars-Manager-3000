# BARS Manager 3000 2.3.34 — инструкция без синей рамки

27.10.2026. Основной EXE и встроенные помощники без цифровой подписи.

У списка разделов инструкции отключена стандартная внешняя рамка Windows (BorderStyle.None), которая могла подсвечиваться синим при наведении и фокусе. Изменение одинаково для обеих тем. Выбор раздела, его фоновая подсветка, прокрутка, поиск и доступ с клавиатуры сохранены. Тексты инструкции не менялись.

Проверки: UserGuideTests 475, GuideDpiTests 626 (реальный DPI тестового процесса 120), Ui2332Tests 533, LayoutFitTests 1684; дополнительно 39 проверок метаданных команд Windows. В тестах проверяется отсутствие внешней рамки до и после фокуса, обе темы и имитация масштаба 100/125/150/200%. Просмотрен снимок тёмной темы. Нативные меню других модулей не менялись.

Сборка против .NET Framework 4.6: bin/Bars Manager 3000 2.3.34.exe. Реальные установки, изменение служб/настроек и перезагрузка не выполнялись. Полный Test.ps1 не запускался. Ограничения PowerShell Base64 в текущем окружении и старого Ui2330Tests из 2.3.33 остаются; эта точечная UI-правка их не исправляет.

В релизе только EXE, RELEASE-2.3.34.md и CHANGELOG.md. Публикация подтверждается отдельно после сверки GitHub.
