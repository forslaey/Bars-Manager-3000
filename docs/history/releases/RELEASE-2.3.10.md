# BARS Manager 3000 — 2.3.10, 21.10.2026

При открытии установки программ больше не скачивается установщик AnyDesk ради определения его версии. Начальная проверка использует сведения Windows и проверенный локальный комплект/кэш. Полная загрузка для уточнения неизвестной версии доступна по явной кнопке «Проверить версии»; при установке пакет также загружается при необходимости. Неизвестная версия не считается доказательством наличия обновления.

Включены изменения интерфейса 2.3.9: блок папки установщиков целиком справа, дополнительный отступ под заголовком, увеличенная высота окна, одинаковые промежутки вокруг чекбоксов. Все четыре программы видны без прокрутки. Кнопки выбора в программах и утилитах находятся на 4 единицы ниже видимых нижних рамок полей. Обе темы; согласованные тексты сохранены.

Реальные испытания обнаружили ещё два дефекта. AnyDesk иногда удалял регистрацию, файл и службу, но оставлял собственный процесс удаления работающим. Теперь после устойчивого подтверждения отсутствия этих трёх признаков завершается только собственное задание деинсталлятора; отмена пользователя сохраняет значение отмены. У Notepad++ резервные файлы несохранённых документов теперь перемещаются в хранилище менеджера до запуска штатного удаления, поскольку сам деинсталлятор может очистить профиль раньше последующей уборки настроек. Путь сохранения записывается в журнал.

Результат: 30 итоговых сценариев программ в выделенной Windows 11 Pro VM прошли. Включены локальные установки/удаления всех четырёх программ без сети, повторная установка после удаления, пропуск одинаковых версий, получение официальных пакетов, настройка доступа, ассоциации, отмена, защита от изменённого пакета, кириллица/пробелы в пути и реальное обновление Notepad++ с блокировкой понижения версии.
