# 2.3.69 — плавная анимация, ровные края и полное завершение

Исправление замечаний по 2.3.68:
- Неопределённый прогресс: сегмент фиксированной длины 96 базовых px (ограничен третью короткого трека), шестисекундный цикл туда-обратно с плавным разворотом. Телепортация из конца в начало исключена. Запрошенный интервал анимации 16 мс; реальная частота зависит от WinForms/UI и нагрузки.
- Заполнение по байтам сглаживается по прошедшему времени с постоянной 450 мс. Системное отключение анимаций учитывается.
- Скруглённый трек, заполнение и движущийся сегмент рисуются непосредственно антиалиасными GraphicsPath с дробными координатами. Обрезка через SetClip удалена: она давала ступенчатую границу.
- Complete рисует полный трек одновременно с 100%, даже до следующего тика таймера. Установка явно начинает новый этап; поздние сообщения progress не заменяют подтверждённый результат. Нижний статус после операции также получает итог.

Проверки: DownloadProgressTests дополнен проверкой полного правого края сразу после Complete, стабильной длины/непрерывности сегмента на 360 кадрах, позднего сообщения установщика и полного растра обеих тем/моделируемых 100/125/150/200%. Все проверки итогового прогона прошли. SoftwareTests 336, SoftwareStorageTests 27, BundleTransportTests 39 прошли. Эти тесты не выполняют реальную установку.

Реальное окно просмотрено при движении неопределённого сегмента и после перехода к подтверждённой установке: полоса заполнена полностью. Preview только в игнорируемой work. Сетевой транспорт не менялся; повторно проверены локальные HTTP full/resume/retry/truncation/hash сценарии. Новое массовое скачивание и реальная установка сторонних программ не выполнялись.
