# BARS Manager 3000 2.3.33 — исправления после ревью

27.10.2026. Программа и оба встроенных помощника без цифровой подписи.

## Исправления

- Отключение IIS/Telnet/TFTP больше не передаёт несуществующий параметр `-All` в `Disable-WindowsOptionalFeature`. Сохранены точный выбранный профиль и `-NoRestart`; включение по-прежнему использует поддерживаемый `-All`.
- Коды установщика 3010/1641 немедленно возвращают требование перезагрузки до обнаружения готовности и настройки удалённого доступа. Коды ошибок также завершают обработку до последующих действий. Успешная установка без перезагрузки проверяется одним снимком обнаружения, который используется дальше.
- Ошибки удаления временного файла/каталога загрузки больше не заменяют исходное исключение загрузки или проверки пакета. Неудачная очистка сообщается отдельно. Удаляется только точный временный файл и пустая частная папка, неизвестные файлы сохраняются. Ошибка обработчика журнала также не скрывает исходную причину.
- Проверка результата установки выделена в отдельный метод, команда установки развёрнута в читаемые блоки. Масштабное разделение Program.cs и переписывание интерфейса намеренно не выполнялись: оно увеличило бы риск несвязанных регрессий. Пользовательские надписи, макеты и функции не перерабатывались.

## Проверки

- WindowsFeatureCommands.Tests.ps1: 39 проверок. Сформированные команды разбираются PowerShell AST, параметры сверяются с установленными командлетами; исходная ошибочная команда с `-All` отклоняется. Системные команды не выполняются.
- ReviewRegressionTests: 47 проверок кодов перезагрузки/ошибок, однократной проверки версий, заблокированного временного файла, ошибки журнала, сохранения исходного исключения и неизвестных файлов.
- Дополнительно прошли UtilityModuleTests 559, SoftwareTests 336, SoftwareMaintenanceTests 32, SoftwareConfirmationTests 18, SoftwareStorageTests 27, Ui2332Tests 533, LayoutFitTests 1684, UserGuideTests 459, KioskTouchTests 204, Core 62, Management 72, ManagedServiceStore 88.
- Build.ps1: успешно против reference assemblies .NET Framework 4.6. Готовая программа в bin/Bars Manager 3000 2.3.33.exe. Для воспроизведения целевых проверок добавлен tests/Run-ReviewRegression.ps1; новые проверки также включены в Test.ps1.

## Известные ограничения

SystemSettingsRegressionTests в текущем окружении не проходит передачу сценария PowerShell: FromBase64String сообщает некорректный ввод. Безопасный вызов воспроизведён и на неизменённой предыдущей bin/2.3.32, поэтому это не объявляется новой регрессией 2.3.33. Причина пока не установлена. Эксперимент с кодировкой не помог и полностью отменён; транспорт не изменён. Настоящие первичные настройки и операции компонентов Windows в этом окружении нельзя считать подтверждённо работающими. Отдельное исправление требует диагностики, а не предположений.

Сохраняется известная особенность старого Ui2330Tests с DPI-манифестом; этот набор не повторялся. Полный Test.ps1 не запускался и не объявляется прошедшим.

Реальные установки/удаления, изменение служб и политик, VM, перезагрузка и физический КСО не выполнялись. Проверки используют макеты и собственные временные файлы. Исправление параметров DISM не заменяет реальное испытание удаления компонентов в выделенной среде.

Состав GitHub Release: только EXE, RELEASE-2.3.33.md и CHANGELOG.md. Публикация считается завершённой только после отдельной проверки GitHub; локальная сборка сама по себе не является публикацией.
