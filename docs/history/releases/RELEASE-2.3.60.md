# 2.3.60 — пропорции окна результатов

Ширина окна уменьшена с1040 до897 базовых единиц за счёт колонки файлов (примерно20% её прежней ширины); колонка действий сохранена. Высота кнопок пересчитывается по масштабу аналогично загрузчику. Стабильный зазор над действиями, нижняя пустая область сокращена по фактическому размещению. Тонкие однострочные строки, три равные кнопки, границы scrollbar и touch сохранены.

50 проверок результатов в двух темах и39 метаданных команд прошли; снимок длинного списка просмотрен. Полный тестовый набор, физический touch и сетевые загрузки не выполнялись. Сборка без подписи. Прежние ограничения общих UI-тестов сохраняются.
