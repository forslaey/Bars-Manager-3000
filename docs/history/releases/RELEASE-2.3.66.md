# 2.3.66 — диагностика без регистрации службы

Добавлен режим диагностики выбранного EXE: регистрация SCM не нужна. Находится единственный доступный процесс по точному полному пути, считываются порты и HTTP.sys. Не запускает EXE автоматически. Если EXE выбран в менеджере, «Диагностика» использует его; иначе выбранную зарегистрированную службу, а без строки предлагает выбор EXE. Несколько процессов с одним путём не выбираются наугад.

Оба режима используют одинаковые проверки принадлежности адреса перед повторным опросом, HTTP/TCP и обнаружение Swagger. Отсутствие Swagger не является ошибкой. TCP подтверждает только соединение, HTTP401/403 подтверждает сервер с требованием доступа; исправность бизнес-операций не заявляется.

Реальный MobileService после исправления пользователем конфигурации: PID15168, HTTP.sys localhost50090, сервер отвечает с требованием доступа, Swagger не обнаружен. WebStore в момент повторного прогона не работает; ранее подтверждённый адрес9010 не подставляется при отсутствии процесса. Banking/Scanner/License/MobileCashDesk повторно проверены без изменения их состояния.

Проверки: самостоятельный EXE/отсутствующий процесс2; hosting3;HTTPsys3;probe11;TCP7;UI4;navigation167;metadata39. Полный Test.ps1, бизнес-операции и физический touch не выполнялись. Не гарантируются дочерние процессы, все варианты конфигураций/локализаций и нестандартные Swagger. Полный аудит39 пакетов не завершён. Framework4.8, без подписи.
