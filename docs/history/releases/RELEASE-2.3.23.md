# Локальная версия 2.3.23 — 23.10.2026

## Интерфейс

- Логотип лаунчера опущен; сохранён промежуток до «Инструменты BARS».
- Окно программ компактнее. При реальных 125% и проверенных размерах ноутбука видны пять строк, действия, журнал и «В меню». Журнал и навигация закреплены отдельно от рабочей области. При большом тексте или малой высоте прокручивается рабочая область; кнопка возврата остаётся на экране. Список поддерживает фирменную прокрутку и существующие сенсорные жесты.
- Уплотнена область выбора службы (184 → 130 единиц). В стандартном окне освободившееся место примерно удваивает высоту журнала.
- Все внутренние MessageBox заменены общим фирменным диалогом для двух тем. Сохранены ответы DialogResult, безопасный ответ по умолчанию, Enter/Escape. Системные окна Windows (UAC, выбор файлов, сторонние установщики) остаются окнами Windows.
- Добавлены заголовки «Журнал установки программ» и «Журнал проверки и настройки».

## Журналы и состояния

- Записи действий служб существовали, но журнал не прокручивался к концу. Добавлен переход к последней записи без захвата фокуса. Названия действий и режимов запуска выводятся по-русски; ошибки и неподтверждённые результаты сохраняются.
- Системные настройки показывают понятные русские статусы вместо True/False, имён параметров реестра и сырых результатов PowerShell. Сводка по каждой группе и краткие подробности политик/папок записываются в журнал.
- Политики паролей сравниваются с согласованным профилем; отсутствие данных не считается применением. Максимальный бессрочный срок -1 корректно учитывается как 0.
- Проверка прав обходит найденные папки и вложенные объекты без изменения ACL. Полный доступ подтверждается только при наличии нужных разрешений, без обнаруженных запретов, пропусков и ошибок. Права только на корне не считаются подтверждением всего содержимого. Ссылки не обходятся.
- Названия: «Политика паролей системы Windows», «Контроль учётных записей», «Защитник Windows». Кнопки политик и SmartScreen: «Применить политики», «Вернуть стандартные политики». Брандмауэр: «Отключить все профили»; защитник: «Временно отключить защиту». Описания строк сохранены.

Настоящие запуск/остановка служб, установки, удаления, изменение политик, перезагрузка и VM в этом проходе не выполнялись. Полный Test.ps1 целиком не запускался; в него подключены новые файлы и тесты. Исправления предыдущих локальных версий 2.3.21/2.3.22 сохранены.
