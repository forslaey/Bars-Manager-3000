# 2.3.59 — однострочные результаты проверки

Окно результатов расширено до 1040×570 базовых единиц. Названия отображаются в тонких однострочных строках, колонка файла расширена. Три равные кнопки имеют фиксированную высоту и зазор от таблицы 16 базовых единиц; размеры не зависят от содержимого. Таблица ограничена целыми строками, полоса прокрутки по её высоте, пустой фон Canvas. Статус отсутствующих файлов: «Отсутствует - будет скачано». В источнике проверки/загрузки переключатель темы скрыт, текущая тема сохраняется.

50 проверок результатов и 11 зеркал, 39 метаданных команд прошли. Снимок длинных однострочных названий в тёмной теме просмотрен. Физический touch, полная загрузка из облаков и полный Test.ps1 не выполнялись. Длинные пути сверх ширины колонки могут обрезаться; глобальная геометрия ограничивается рабочей областью экрана. Прежние ограничения общих UI-тестов сохраняются. Сборка без подписи, .NET Framework 4.6.
