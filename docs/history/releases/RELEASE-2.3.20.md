# 2.3.20 — ассоциации Chrome и единый вид окон

Изменения подготовлены 22.10.2026; публикация запрошена 23.10.2026. Сборка без подписи, включая встроенные помощники. [Релиз GitHub](https://github.com/forslaey/Bars-Manager-3000/releases/tag/v2.3.20).

- Отдельная изначально снятая галочка назначает Chrome для всех зарегистрированных им типов файлов и ссылок. Список читается из установленного Chrome; поддерживаемые PDF, изображения и прочие типы включаются по его регистрации. Используется существующий системный профиль с резервированием и сохранением посторонних ассоциаций. Для текущего пользователя открываются параметры Windows для подтверждения. Применение ко всем существующим пользователям может требовать повторного входа; ограничения редакций Windows и внешних политик сохранены. Реальное применение нового профиля пока не проверялось.
- Компактная центрированная область только в лаунчере и распаковке утилит. Службы, библиотеки, программы, системные настройки и компоненты Windows растягиваются на окно. Тумблер автообновления служб закреплён справа, как в библиотеках. Проверялись также портретные макеты.
- Системная строка заголовка всех модулей и тематических диалогов соответствует светлой/тёмной теме. Тема применяется при создании и пересоздании окон, а у модулей — также при переключении темы. Использован общий DWM-механизм с совместимым резервным атрибутом старых Windows; неподдерживаемые ОС не приводят к сбою.
- Общий отступ шапки опускает логотип относительно верхнего края. Названия служб, библиотек, программ и первичных настроек имеют одинаковые координаты, размеры области и шрифт. Компактное окно утилит сохраняет подходящую ему высоту заголовка.
- Только в установке программ удалена внешняя скруглённая карточка вокруг таблицы. Оставлена сама таблица; внешние карточки других модулей сохранены.
- Версия основного файла и встроенных помощников повышена до 2.3.20. README актуализирован; CHANGELOG.md содержит сводку и ссылки на подробности 2.3.14–2.3.20. Исторические файлы выпусков сохранены.

Проверки: HeaderStyleTests 106 (включая 74 нативные проверки строки заголовка), ResponsiveLayoutTests 5168, LayoutFitTests 1652, SoftwareConfirmationTests 27. Проверялись обе темы и портретные макеты; физический КСО, настоящая смена DPI между мониторами и применение нового профиля Chrome ещё не проверены. Подробности см. в начале DEVELOPMENT-STATE.md. Реальные установки, действия служб, настройки рабочей Windows и VM этим этапом не выполнялись.
