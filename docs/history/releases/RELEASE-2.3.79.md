# BARS Manager 3000 2.3.79

## Запуск

- Один подписанный EXE для Windows x64, со значком и сведениями о версии.
- Нативный запускатель проверяет .NET Framework до открытия менеджера. Локальный пакет 4.8 ищется в подпапке `_barsmanager3000`.
- Защищённый кэш ускоряет повторный запуск от администратора.

## Изменения

| Модуль | Что изменилось |
| --- | --- |
| Библиотеки и .NET | Ручной выбор папки, поддержка структуры комплекта, обновлённая прокрутка. |
| Службы | Высота таблицы растёт при разворачивании. Закрытие окна прерывает ожидание процедуры. |
| Первичные настройки | Часовой пояс, обои для КСО и касс, отдельные замеры фоновой проверки. Управление Defender удалено. |
| Установка программ | Пустые поля пароля при открытии диалога, понятные сообщения об ошибках настройки доступа. |

Сборка предназначена для проверки в эксплуатации. Реальная установка Framework на чистом Server 2019 и применение обоев при входе второй учётной записи требуют отдельной проверки.
