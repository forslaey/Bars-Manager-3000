Проверка Windows выполняется в фоне, её результат показывается до сканирования установщиков. Открытие модуля и смена локальной папки не обращаются к интернету; сетевые версии проверяются по явной кнопке «Проверить версии».

Локальные пакеты и кэш по-прежнему проверяются по метаданным, SHA-256 и подписи. Для неизвестного неподписанного 7-Zip автоматический запуск сетевой проверки хеша при открытии запрещён: неподтверждённый пакет не предлагается до успешной явной проверки. Защита установщика не ослаблена. Перед установкой сохранены прежние повторные проверки пакета и запрет понижения версии. Если локального пакета нет, для получения сетевого предложения нужно нажать «Проверить версии».
