# 2.3.45 — компактный загрузчик и согласованный интерфейс

Без цифровой подписи, .NET Framework 4.6.

## Изменения
- Загрузчик стал компактным модулем: два фирменных переключателя «Библиотеки и .NET» и «Утилиты BARS», поле папки, журнал, единый скруглённый градиентный прогресс с процентами и одинаковые нижние кнопки. Постоянная таблица каждого файла, программы, выбор потоков и переключатель «Авто» убраны. Программы скачиваются своим модулем. Параллельность управляется внутри, без пользовательской настройки.
- Проверка выводит отдельное упрощённое модальное окно только с отсутствующими/отличающимися файлами и понятным действием. Актуальные файлы в него не попадают. Проверки, различия, результаты скачивания и ошибки отражаются в журнале простым языком. Защита изменённых локальных файлов сохранена.
- Из лаунчера «Скачать комплект» открывает самостоятельный кешируемый модуль через ManagerApplicationContext: лаунчер закрывается; «В меню» возвращает его. Убраны многоточие и подпись версии. Кнопка слева, у границы карточек; размеры совпадают с «Инструкция» и «О программе» справа.
- Убраны обработчики клика с растянутых статусных надписей библиотек и программ: пустая нижняя область больше не открывает загрузчик.
- «Открыть журнал» в библиотеках восстановлена ширина 180 базовых единиц и слот 190 с отступом; остальные кнопки 140×40.
- Лаунчер и установка программ: FixedSingle, без ручного растягивания, максимизация сохранена. Распаковка утилит: FixedSingle, максимизация отключена. Существующая адаптация DPI и ограничения рабочей областью сохранены.
- Инструменты очистки частей/старых версий убраны из основного UI для минимализма; безопасные служебные реализации и тесты сохранены, автоматического удаления не добавлено.

## Проверки
Пересобран целевой набор: BundleUiRevisionTests 24, BundleLayoutTests 48 (обе темы, моделирование 100/125/150/200%), BundleFailureTests 29, BundleUpdateTests 18, BundleTests 29, BundleTransportTests 22, SoftwareStorageTests 27, SoftwareTests 336, NavigationTests 167, SoftwareConfirmationTests 18, TouchGridTests 39, LibraryManagerTests 155, UtilityModuleTests 583, UserGuideTests 475, TouchTextTests 11, метаданные команд 39. Все перечисленные проверки прошли: 2020 утверждений. Просмотрены снимки компактного окна светлой/тёмной темы и моделирования 200%.

Это не полный Test.ps1; прежние ограничения Base64/Ui2330 не объявляются устранёнными. Физический сенсорный КСО, все разрешения/мониторы и реальное переключение DPI требуют последующего аппаратного прогона. Массовые загрузки из облака, установки, операции служб и изменение C:\Библиотеки не выполнялись. Google-зеркало пока не подключено; каталог BARS вне спринта. Кнопка «В меню» в загрузчике, открытом вложенным диалогом при отсутствии комплекта, закрывает этот диалог к непосредственному родителю; самостоятельная навигация реализована для входа из лаунчера.
