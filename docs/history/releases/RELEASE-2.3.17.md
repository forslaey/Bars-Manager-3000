# 2.3.17 — журналы библиотек, сенсорный список, системные настройки

22.10.2026. Локальный выпуск без цифровой подписи.

- Для каждой очереди установки, обновления, удаления или переустановки создаётся отдельный TXT в «Библиотеки/Журнал установки библиотек». Имя: «Журнал от <компьютер> yyyy-MM-dd HH-mm-ss-fff.txt». Запись сохраняется после каждого сообщения, включая результаты отдельных компонентов, ошибки и отмену; файл одной очереди не смешивается со следующей или периодической проверкой. UTF-8 BOM. Ошибка записи видна пользователю, полная копия активной очереди остаётся в памяти для повторной записи при завершении. При невозможности создать журнал очередь не запускает установщики. Кнопка «Открыть журнал» открывает выбранный каталог.
- Журнал содержит исходные версии, выбранное действие, результат проверки, код завершения, путь к подробным логам установщика и дальнейшие шаги.
- Перезагрузка доступна вручную в состоянии покоя; во время проверки/установки заблокирована. По нажатию остаётся подтверждение. Установка сама по себе не означает обязательную перезагрузку.
- Список библиотек принимает сенсорный свайп с системной инерцией; касание подтверждается по отпусканию, движение не переключает чекбокс. Мышь остаётся на прежнем обработчике. WinForms DataGridView прокручивает вертикально по строкам, пиксельная плавность не заявляется. Проверка на реальном сенсорном КСО остаётся за пользователем.
- В первичных настройках отдельная группа SmartScreen для запуска приложений: выключение через штатную политику Windows, стандарт — убрать заданную политику и вернуть локальный Warn. Edge, Smart App Control и другие механизмы не меняются. GPO/MDM могут переопределить результат. Источник: https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-windowsexplorer#enablesmartscreen ; сопоставление также сверено с WindowsExplorer.admx.
- Права папок: по отдельной кнопке с подтверждением помощник с правами администратора находит существующие DataKrat и Bars строго в корне готовых локальных/съёмных дисков NTFS/ReFS. Пользователи (S-1-5-32-545), Администраторы (544), SYSTEM (18) получают FullControl; каталоги — с наследованием. Имена и язык Windows не нужны. Обход включает защищённые от наследования дочерние объекты. Ссылки/junction не обходятся, владельцы не меняются, запрещающие правила не удаляются. При отказе или Deny показывается ограничение, успех не имитируется. FAT/exFAT не поддерживают эти ACL; сетевые и оптические диски исключены. Автоматического применения при запуске менеджера нет.

Проверки: LibraryJournalTests 31, TouchGridTests 39, WindowsRestartTests 30, RapidSelectionTests 52, UiPolishTests 103 (10 foreground-проверок пропущены без активного лаунчера), LayoutFitTests 1868 — обе темы и имитация геометрии 100/125/150/200%, NewSettingsTests 226, UserGuideTests 459. Windows PowerShell 5.1: синтаксис генерируемых скриптов, mock-проверки SmartScreen и существующих настроек; реальные ACL только во временном макете — повторное применение, наследование, пропуск junction, сохранность соседнего каталога и честный отказ при существующем Deny. Рабочие папки, настройки хоста и библиотеки не менялись; VM-установки не проводились. Физический сенсор не испытан.

Права папок исполняемых файлов позволяют пользователям менять программы служб — пользователь явно выбрал полный доступ после пояснения последствий. Подпись и публикация текущего выпуска не выполнялись.
