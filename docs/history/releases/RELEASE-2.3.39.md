# BARS Manager 3000 2.3.39

По просьбе пользователя — короткий проход без больших регрессий и загрузок установщиков.

- Подписи архитектуры: AnyCPU - универсальная разрядность / Разрядность x86 / Разрядность x64.
- У служб фирменная полоса прокрутки вместо белой нативной, строка переключателя выше и отцентрирована по вертикали.
- Общий список библиотек восстановлен, выпадающий фильтр удалён. Шесть кнопок панели равной ширины; Сканировать систему и Проверить обновления .NET перед отменой.
- Окно .NET сразу показывает каталог с проверкой наличия файлов в выбранной папке; отсутствующие выделены красным. Добавлены четыре варианта .NET 7 при отсутствии в каталоге. Сеть запрашивается только кнопкой.
- Для присутствующих 6.0.36 и 7.0.20 запрос метаданных пропускается; отсутствующие можно скачать. .NET 11 RC обрабатывается отдельно от стабильных версий, сравнение через LibraryVersions.Compare. Существующий механизм установки RC в библиотечном модуле сохраняется.

Проверки: сборка .NET Framework 4.6 без подписи. Большие прежние тесты не запускались по просьбе пользователя; загрузка/установка и физический КСО не проверялись. Нужна пользовательская проверка UI/RC и отсутствующих пакетов. Старые удаления releases не включать в коммит.
