# BARS Manager 3000 — 2.3.13, 21.10.2026

Свежие установщики программ теперь сохраняются непосредственно в `_soft` выбранного комплекта библиотек. Выбор `Библиотеки` без `_soft` показывает будущий путь и создаёт папку только при загрузке; выбор самой `_soft` не добавляет второй уровень. Если выбран контейнер с подпапкой `Библиотеки`, используется она. Менеджер может находиться в другом месте: местом загрузки управляет выбранный источник, а не путь процесса. Когда источник ещё не известен, перед загрузкой предлагается выбрать его.

Сначала файл полностью скачивается во временный каталог внутри целевой `_soft`, затем проверяется и публикуется в её корень. Только после этого без корзины удаляются распознанные более старые установщики той же программы и разрядности. При совпадении имени выполняется замена с откатом, если переместить новый файл не удалось. Используются перемещения на том же томе, без File.Replace; код не требует NTFS для этой операции. Ошибка загрузки, проверки или отмена до фиксации оставляет прежние файлы. Неизвестные/посторонние файлы и более новые версии не удаляются. Если старый файл занят или удалить его нельзя, новый сохраняется, а проблема записывается в журнал. При недоступном/защищённом от записи носителе нет скрытого переключения места новой загрузки на AppData.

Новые загрузки больше не попадают в пользовательский SoftwareCache; старый кэш пока читается для совместимости. Самостоятельная очистка старого пользовательского кэша в эту задачу не входила. Скачанные в `_soft` установщики остаются после установки для использования на других компьютерах. Проверка версий по-прежнему получает только метаданные; установщики загружаются только при установке/обновлении.

В менеджере служб поле «Режим запуска» укорочено до 80% прежней рабочей ширины по схеме пользователя. Поле выше и сохраняет вертикальный центр; выпадающий список имеет достаточно ширины для длинного режима. Только у этого поля отключены смена оформления при наведении и стандартное оформление Windows, вызывавшее визуальный рывок; рамка, текст и стрелка рисуются в фирменной палитре. Остальные списки сохраняют прежнее поведение. Светлая и тёмная темы проверены.

## Проверки

- SoftwareStorageTests: 27 проверок на временных копиях подписанных пакетов — создание/нормализация пути, корень диска, путь с кириллицей/пробелами, удаление старой версии, сохранение посторонних/повреждённых файлов, замена одинакового имени, откат при заблокированном новом файле, отказ по хешу, отмена перед фиксацией, сохранение более новой локальной версии, обработка занятого старого файла и сетевой ошибки.
- Живая загрузка официального AnyDesk 9.8.2 в новую временную `Библиотеки\_soft`: проверенный файл оказался непосредственно в `_soft`, временные каталоги удалены; установщик не запускался.
- StartupModeUiTests: 72 проверки ширины, высоты, центрирования и неизменности изображения/координат при наведении, обе темы, имитация 100/125/150/200%. Снимки просмотрены.
- SoftwareTests 393; SoftwareStartupTests 33; SoftwareVersionCheckTests 51; SoftwareMaintenanceTests 32; LayoutFitTests 1492; ThemeTests 607; RapidSelectionTests 52.
- SigningTests: 13 проверок основного файла и обоих встроенных помощников, меток времени, неверного сертификата и повреждённых файлов. Состояние доверенных хранилищ до/после одинаково; профиль signing.json для проверки не обязателен при явном отпечатке.

Испытания файлов выполнялись во временных папках текущего компьютера; реальный USB/FAT/exFAT-носитель не подключался. Проверены операции перемещения, подходящие этим файловым системам, но аппаратный обрыв питания/извлечение флешки не воспроизводились. Реальные установки/удаления, операции служб и смена настроек Windows в этом проходе не выполнялись; VM не запускалась. Предыдущие реальные испытания программ в VM описаны в SOFTWARE-TEST-2026-10-21.md и не выдаются за повтор на этой версии.
