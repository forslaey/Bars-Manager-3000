# 2.3.72 — общий прогресс очередей

Удалён неопределённый движущийся сегмент. Полоса заполняется только слева направо по измеримому прогрессу. Неизвестный этап сопровождается текстом и сохраняет достигнутую долю; выдуманных процентов установщика нет. Сглаживание относится только к переходу между измеренными значениями. Пустой трек/рамка и геометрия шести модулей сохранены.

- Программы: получение/проверка пакета и подтверждённая установка — задачи очереди. Байты загрузки учитываются внутри задачи. Все подготовленные пакеты составляют первую часть, установки — вторую. Массовое удаление и настройка доступа также увеличивают общий счётчик после успешного шага.
- Библиотеки: подтверждённые компоненты очереди; проверки системы сообщают число обработанных компонентов. Неизвестный текущий результат, ошибка, отмена и требование перезагрузки не становятся успешными 100%.
- .NET: общий прогресс по выбранным установщикам с байтовой долей текущего пакета; проверка версий считает обработанные каналы.
- Комплект: загрузка сохраняет общую байтовую долю, сверка считает проверенные файлы после получения каталога.
- Утилиты: реальные обработанные файлы внутри копирования, затем подготовка запуска и ярлыков. До успешного сохранения новой папки копирование не считается завершённой задачей.
- Первичные настройки: применение и последующая проверка — отдельные шаги. Явная проверка — получение данных и обработка результата. Фоновое открытие остаётся без анимации и без фиктивного успешного выполнения.

Общая доля задач не является оценкой доли оставшегося времени. После ошибки/отмены сохраняется частичная доля. Запоздалые callbacks предыдущей операции отбрасываются. Встроенная инструкция обновлена.

Проверки:
- DownloadProgressTests: 563 в итоговом прогоне: дроби 1/3 и 2/3, байты внутри задачи, отсутствие сброса при проверке, сохранение частичного результата при ошибке, копирование файлов, завершение, поздние сообщения, шесть модулей/две темы/моделируемые 100–200%/малая высота и локальный HTTP.
- ToolsRemovalTests расширен: 28 проверок, включая фактические сообщения прогресса копирования временных файлов, монотонность и завершение задачи только после результата рабочего действия.
- Настоящие скачивания официального 7-Zip 26.05 и .NET Runtime 8.0.33 x64, подписи/метаданные/хеши, отмена и неверный SHA-512 прошли. Установщики не запускались; файлы только в work.
- OpeningProgressTests, UtilityModuleTests 583, SoftwareTests 336, NewSettingsTests 190, SystemSettingsRegressionTests 100, UserGuideTests 451, BundleTransportTests 39, SettingsSpacingTests 6 прошли.
- Реальное окно демонстрационной очереди просмотрено; заполнение до 100% соответствует 5 из 5 задач. Предыдущий бегущий сегмент отсутствует в коде отрисовки.
