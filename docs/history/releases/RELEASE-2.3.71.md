# 2.3.71 — состояния прогресса и шесть модулей

Исправлено самопроизвольное движение в программах: блокировка кнопок при автоматической проверке больше не означает установку. Настоящая локальная проверка программ проверена отдельно: начало и завершение без движения и без 100%. После ошибок/отмены/завершения операций анимация останавливается. Обычный текст ожидания — «Ожидание действия».

Единый сглаженный контур Border применяется к треку в обеих темах. Фоны трека и зелёный акцент сохранены с учётом темы.

Прогресс добавлен в распаковку утилит, системные библиотеки и первичные настройки. Для действий без измеримого объёма используется спокойный сегмент без выдуманных процентов. Утилиты завершаются после распаковки и действий с ярлыками/совместимостью; библиотеки — после подтверждения всех шагов очереди; перезагрузка, отмена, ошибка и частичный итог не становятся успехом. Первичные настройки отдельно выполняют проверку после применения, ошибки чтения не дают 100%. Начальная проверка настроек остаётся неподвижной.

Введён явный жизненный цикл BeginOperation/FinishOperation и callbacks с номером операции: позднее сообщение не может отменить итог или перезаписать следующую операцию. Нижние подписи утилит/настроек тоже защищены от позднего обновления.

Компоновка: утилиты 520×604 вместо 520×500 для отдельного блока; библиотеки 1120×904 вместо 1120×800 с сохранённой высотой журнала; первичные настройки используют адаптивную область над журналом. Статус/меню и нижние действия сохранены. Отступы первичных настроек до/после действий — 20 базовых px, вместо сравнения с прежним положением журнала тест теперь сравнивает начало нового блока.

Проверки: общий прогресс в шести модулях, обе темы, моделируемые 100/125/150/200%, малая высота, состояния ожидания/отмены/ошибки/успеха, поздние callbacks; настоящая локальная проверка программ; SoftwareTests 336; SoftwareMaintenanceTests 32; UtilityModuleTests 583; ToolsRemovalTests 18; NewSettingsTests 190; SystemSettingsRegressionTests 100; SettingsSpacingTests 6; SettingsFooterLayoutTests 32; ToolsCompactTests 56. Финальный DownloadProgressTests: 916 проверок; OpeningProgressTests: настоящая локальная проверка программ без анимации; BundleTransportTests: 39 сетевых проверок локального HTTP (докачка/повтор/обрыв/неверный хеш).

Снимки новых модулей просмотрены; реальные окна с демонстрационной анимацией также просмотрены. Установка внешних пакетов и применение системных настроек на рабочем ПК не выполнялись. Временные операции утилит выполнялись только на созданных тестовых данных. Полный Test.ps1, физический touch/КСО и эксплуатационная матрица не выполнены. Сборка Framework 4.8 без подписи. Публикации нет, preview только в work.
