# BARS Manager 3000 2.3.37

Неподписанный выпуск. Уточнение выравнивания по пояснительным скриншотам пользователя от 27.10.2026.

## Изменения

- Службы: заголовок модуля сохранён на месте. Подсказка выбора файла и «Службы BARS» выровнены по видимому левому краю заголовка, включая смену выбранного файла. Ряд кнопок установки/удаления перенесён выше, а «Службы BARS» и переключатель проверки — непосредственно перед списком служб. Высоты строк переставлены вместе с содержимым; суммарная высота блока не выросла.
- Библиотеки: заголовок смещён вправо по фактическому началу текста сводки; строка каталога имеет тот же видимый край.
- Программы: заголовок начинается по левой границе таблицы и опущен в общую строку с подписью «Папка установщиков:». При недостаточной ширине длинное название переносится; высота общей строки увеличивается за счёт пустого промежутка сверху, без наложения на поле/кнопку и без обрезки названия.
- Утилиты, первичные настройки и компоненты Windows: заголовки начинаются по левой границе своей карточки/таблицы. У утилит убрано дополнительное переопределение отступа, которое возвращало прежнее смещение.
- FlushLabel получил необязательное выравнивание по видимой кромке букв. Учитываются поля шрифта, GDI-отступы и DPI; измерения кешируются. Одних одинаковых координат Label для такого выравнивания было недостаточно. Прочие подписи без этой настройки рисуются как раньше.

## Проверки

InkAlignmentTests: **128** сравнений по растру полного окна в обеих темах при моделируемом масштабе 100/125/150/200%. Проверены видимые края текста шести модулей, разные имена выбранных служб, порядок строк и переключателя, совпадение строки заголовка программ с подписью папки и полная вместимость названия. Дополнительно такой же набор прошёл по снимкам отдельных подписей. Снимки всех шести модулей в обеих темах сохранены; шесть снимков просмотрены вручную.

Navigation 167, Software 336, Ui2332 533, WindowSession 58, ResponsiveLayout 5240, LayoutFit 1684, HeaderStyle 122; Core 62, Management 72, ManagedStore 88, ReviewRegression 47, метаданные команд Windows 39 — прошли. Прежние тесты общих координат заголовков и расположения папки обновлены под явно уточнённые пользователем ориентиры; проверки вместимости сохранены.

Сборка .NET Framework 4.6, встроенные помощники x86/x64, прежняя иконка; без подписи. Установки, удаление, работа со службами и системные политики не выполнялись и их логика не менялась. Физический КСО и реальные переключения DPI мониторов не тестировались. Полный Test.ps1 не объявляется прошедшим: прежние ограничения Base64/Ui2330 остаются из 2.3.33. Сессия окон из 2.3.36 сохранена.

Релиз содержит только EXE, RELEASE-2.3.37.md и CHANGELOG.md; личные TXT-памятки остаются в исходниках.
