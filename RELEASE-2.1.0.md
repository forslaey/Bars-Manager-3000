# Версия 2.1.0 — 19 октября 2026

- Кнопка «Выбрать всё» отмечает компоненты; повторное нажатие «Снять выбор» снимает отметки. Неподходящие для ОС строки исключены.
- Модуль библиотек называется **Bars Component Manager 3000** в окне, лаунчере и «О программе».
- Кнопки лаунчера увеличены по высоте и отодвинуты от краёв карточек; заголовки выровнены.
- RuntimePack Full исключён. Встроенный в сборник VC++ **Lite обязателен** для обоих установочных профилей.
- Сборник VC++ разделён на старый профиль и v14. Проверяются 2012/2013 и современный v14, обе разрядности; версия старого профиля не сравнивается с номером обёртки 14.x.
- Добавлены фактическая версия в системе и краткая рекомендация. Старые версии предлагают обновить, новые пропускаются; откат старым комплектом блокируется. .NET учитывает ветки, разрядность и полную предварительную версию.
- Удаление и переустановка используют действующие регистрации продуктов; файлы, оставшиеся после удаления, сами по себе не подтверждают установку. Исправление пустого рабочего каталога при запуске штатного деинсталлятора из 2.0.3 сохранено.
- Новый порядок папок и числовые префиксы имён распознаются из метаданных. В комплекте 39 установочных файлов / 40 логических записей из-за двух профилей VC++.

- Добавлена отмена активной операции с предупреждением и выход по подтверждению. Крестик закрывает менеджер целиком, «В меню» возвращает лаунчер. Отдельный сигнал отмены передаётся повышенному помощнику, собственное дерево процессов закрывается, затем при необходимости завершается принудительно. Проверка/копирование файлов тоже прерываются. Посторонние процессы и системная служба Windows Installer не завершаются; откат сторонних установщиков не гарантируется.

## Проверка

Пройдено **1829 автоматических проверок**, включая 14 проверок отмены и 68 проверок UI/навигации.

Полный набор автоматических тестов: управление службами, каталог, версии, профили VC++/Lite, команды MSI/Burn/Inno, запуск инертных дочерних процессов, обе темы, ввод и навигация, лог-архивы. Установщики и деинсталляторы библиотек не выполнялись.

На текущем компьютере проверка в режиме чтения подтвердила 40 из 40 записей. Современный VC++: 14.52.37025.0 x86/x64; старые: 11.0.61030.0 и 12.0.40664.0. Более новые .NET 8/9/10 распознаются, .NET 11 RC подтверждается полностью. Подготовленные команды удаления проверены без выполнения; MSXML предоставлен Windows и отдельное удаление ему не предлагается.

Сборка **без цифровой подписи**, включая встроенные помощники. Проверка на чистой виртуальной машине с настоящей очередью установки/удаления остаётся необходимой перед массовым использованием. Подробнее: [руководство](MANAGER-V2.md).

Основания правил: [поколения Visual C++](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/), [.NET runtime selection](https://learn.microsoft.com/en-us/dotnet/core/versions/selection), [версии .NET Framework](https://learn.microsoft.com/en-us/dotnet/framework/install/how-to-determine-which-versions-are-installed), [задачи Inno Setup](https://jrsoftware.org/ishelp/topic_setupcmdline.htm), [режим обновления MSI](https://learn.microsoft.com/en-us/windows/win32/msi/reinstallmode).
