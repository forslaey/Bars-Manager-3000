Установки, удаления, ассоциации и пароли клиентов основной Windows не менялись.

Испытатель `tests/integration/SoftwareIntegration.cs` отказывается запускаться вне BARS-LAB-01. Он загружает упакованную сборку и использует её настоящее ядро через аутентифицированный LibrarySession, процессы заданий и рабочие команды. Открытие формы отдельно проверялось настоящим обработчиком Shown.

## Найденные проблемы и исправления

1. Открытие формы загружало полный AnyDesk для получения неизвестной версии. Убраны GET-проба установщика и автоматическое разрешение версии через скачивание при Shown/смене папки. Начальная проверка использует Windows и локальный комплект/кэш; явная проверка версий и установка сохраняют возможность загрузки. В VM FileSystemWatcher не зарегистрировал создание AnyDesk `.part` при открытии формы с установленным клиентом.
2. AnyDesk `--remove` мог оставить собственный процесс после исчезновения файла, регистрации и службы. После двух секунд устойчивого отсутствия этих признаков завершается только задание менеджера. Сам флаг `--remove` соответствует [документации AnyDesk](https://support.anydesk.com/docs/command-line-interface-for-windows). Реальная отмена не превращается в успешное удаление.
3. Резервные файлы несохранённых документов Notepad++ ранее сохранялись слишком поздно: штатное удаление успевало стереть профиль. Теперь сохранение выполняется в пользовательском UI-контексте до повышенного удаления. Контрольный резервный документ пережил реальное удаление; путь записан в журнал.

Исходные неудачи не посчитаны успешными: зависание AnyDesk, потеря искусственного резервного документа до исправления, преждевременное утверждение теста сразу после выхода NSIS-родителя. Для внешнего удаления тест теперь дожидается фактического исчезновения регистрации/файла. Первый запрос старого релиза к GitHub API получил HTTP 403; испытание повторено по фиксированному официальному URL с опубликованным SHA-256 и проверкой подписи, без ослабления доверия к файлу.

## Что не подтверждено

Это испытание одной Windows 11 Pro, а не всей матрицы Windows 10/11/Server и не любых будущих версий пакетов. Полный интерактивный путь UAC, физическая смена DPI/монитора и вход удалённого оператора с другого компьютера не автоматизированы. Для доступа проверены выполнение команд клиентов и сохранение пароля; пользователь ранее отдельно подтвердил работу паролей. Ассоциации проверены по применённой конфигурации и регистрации; новый вход другого пользователя и открытие каждого расширения не автоматизированы. Удаление настроек других пользовательских профилей не предусмотрено и не заявляется.

Сырые отчёты находятся только локально в игнорируемой `work/vm-software-20261021/final-results`, исходные неудачные прогоны сохранены отдельно. Учётные данные, пароли и сторонние установщики в Git не добавляются. Изменения этого этапа пока локальные.
