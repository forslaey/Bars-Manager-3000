# Версия 2.1.1 — локальная сборка, 19 октября 2026

- «О программе» менеджера служб содержит название Bars Service Manager 3000 и описание «Управление службами BARS». Общее описание двух модулей в лаунчере сохранено.
- Заголовок карточки и кнопка компонентов в лаунчере: «Менеджер компонентов». Сам модуль сохраняет имя Bars Component Manager 3000.
- Авторский текст разделён явно на две строки после «нейросети,». Обе строки помещаются рядом с кнопкой закрытия в обеих темах.
- «В меню» из менеджера служб сохраняет намерение возврата до завершения модального закрытия. Отказ от закрытия занятого менеджера сбрасывает это намерение.
- Модули открываются с видимым лаунчером как явным владельцем модального окна. Лаунчер остаётся недоступным под модулем; Windows сохраняет связь окон при первом и повторном запуске. Крестик закрывает программу, «В меню» возвращает к лаунчеру.

Пройдена 1871 автоматическая проверка, в том числе 109 UI-проверок: реальные модальные переходы для обоих модулей, первые и повторные открытия компонентов, подтверждение отказа от возврата при работе службы, окна сведений и обе темы. Обычный Test.ps1 использует тестовые каталоги и не запускает настоящие службы или установщики. Отдельно в изолированной VM пройдены 24 вызова ядра менеджера для .NET Runtime и ASP.NET Core 6.0.36 x86/x64: установка, повторный вызов установки (пропуск), переустановка, удаление и второй цикл установки/удаления. Состояние проверено независимо через dotnet. Повреждённая ARP-регистрация воспроизведена; автоматическое исправление этого случая ещё не реализовано. Полная матрица чистых ОС не проверялась.

Сборка без подписи, включая помощников. Исходники и документация подготовлены к отправке в main по просьбе пользователя 20.10.2026. Новый бинарный релиз не публикуется; releases/v2.1.0 сохранён.
