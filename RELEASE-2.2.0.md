# BARS Manager 3000 2.2.0 — версия для проверки новых функций

Лаунчер содержит четыре карточки в сетке 2×2: службы, библиотеки, компоненты Windows и утилиты BARS. Размеры кнопок, поля и подписи согласованы в светлой и тёмной темах. Основной EXE и встроенные помощники собираются без подписи, с прежней фирменной иконкой.

## Компоненты Windows

«Проверить настройки компонентов» открывает отдельное окно. Проверка выполняется через повышенный помощник; при необходимости Windows покажет UAC. Само открытие окна ничего не устанавливает.

- IIS показан одной строкой в группе для модуля «Отчёты для арендаторов». Профиль содержит ровно 27 IIS-компонентов, считанных с настроенного пользователем компьютера 20.10.2026; полный список — `WindowsComponents.Profiles` в `src/WindowsComponents.cs`.
- Telnet Client и TFTP Client находятся в общей группе «Компоненты для fiLinn, piglet».
- Состояния различают установленное, отсутствующее, частично включённое, ожидающее перезагрузки и недоступное в конкретной Windows. Ошибка чтения не считается отсутствием компонента.
- Установка отмеченного набора использует штатный DISM PowerShell с `-All -NoRestart`. Windows может потребовать Windows Update или источник компонентов. После операции выполняется новое чтение состояний. Общая служба обслуживания Windows не завершается принудительно; во время операции окно просит дождаться завершения.

## Распаковка утилит

Источник — `_tools` в папке библиотек рядом с EXE либо в ранее выбранном каталоге. Можно вручную выбрать `_tools` или содержащую его папку. При отсутствии источника программа ничего не копирует до его выбора.

Выбери локальный диск: назначение всегда `<диск>:\DataKrat\_tools`. Подпапки fiLinn, Piglet и WinSCP копируются целиком; версия в имени папки может меняться. Если для одной утилиты найдены сразу несколько подходящих папок, требуется уточнить комплект, а не угадывается версия.

Копирование сначала выполняется во временную соседнюю папку. Существующие файлы настроек в совпадающих папках не заменяются; прежнее дерево сохраняется как `_tools-backup-<дата>-<идентификатор>`. При ошибке или отмене до публикации действующая папка сохраняется. Копирование не запускает EXE. Ссылки и точки подключения не обходятся.

Создаются четыре ярлыка на рабочем столе текущего пользователя:

| Имя | EXE | Иконка |
| --- | --- | --- |
| Piglet | DK-QStart.exe | DK-QStart.exe,0 |
| fiLinn | cspPanel.exe | cspPanel.exe,0 |
| tftpd32 | tftpd32.exe | tftpd32.exe,0 |
| WinSCP | WinSCP.exe | WinSCP.exe,0 |

Для этих четырёх EXE задаётся свойство совместимости «Запускать от имени администратора» **для текущего пользователя** (`HKCU` AppCompatFlags/Layers, RUNASADMIN). Сам EXE и его подпись не редактируются. Другие параметры совместимости сохраняются, конфликтующие уровни запуска заменяются. Запрос UAC остаётся включённым. Настройку записывает пользовательский интерфейс, а не помощник под возможной другой администраторской учётной записью.

Повторная распаковка обновляет собственные ярлыки. Чужой одноимённый ярлык не заменяется: для нового добавляется короткий идентификатор. Абсолютные пути иконок папок в `desktop.ini` исправляются под выбранный диск. `_tools` исключён из поиска установщиков библиотек.

## Перезагрузка после библиотек

Для Inno добавлен `/RESTARTEXITCODE=3010` к существующему `/NORESTART`. MSI сохраняет `REBOOT=ReallySuppress`. У каждого собственного процесса установщика перед запуском удаляются права локальной и удалённой перезагрузки; токен менеджера не меняется. Если ограничение не удалось применить, процесс не запускается.

При коде 3010/1641 очередь приостанавливается, выбор оставшихся компонентов сохраняется. После открытия менеджера восстанавливается только выбор: рекомендации нужно проверить и действие подтвердить заново. Автоматического повторного удаления/переустановки нет. В модуле библиотек добавлена кнопка перезагрузки; немедленная перезагрузка запрашивается только после явного подтверждения с ответом «Нет» по умолчанию. Принудительное закрытие приложений не запрашивается.

Это ограничивает штатные установщики и их собственные дочерние процессы. Отдельная системная служба или нестандартное действие стороннего пакета может работать вне этого токена. Причина прежней перезагрузки VC++ не доказана; проверка самого репака в VM отложена по просьбе пользователя. Абсолютная гарантия для произвольного стороннего EXE не заявляется.

## Проверка и границы этой версии

`Test.ps1` проверяет ядро, UI, обе темы, операции с инертными файлами/процессами. Новый набор (437 проверок) включает имитацию геометрии масштабов 100/125/150/200%, копирование с повторным запуском и отменой, сохранение настроек/резервной копии, четыре имени и пути ярлыков, иконки, права дочернего процесса и сохранённый выбор очереди.

Дополнительный явный `Test.ps1 -UtilitySmoke` из уже повышенного тестового сеанса выполняет только чтение компонентов Windows через настоящий аутентифицированный IPC-помощник, копирование текущего комплекта утилит во временную папку и сверку 136 файлов по SHA-256. Проверяет настоящие EXE-иконки и параметры запуска от администратора для временных путей, затем удаляет тестовые настройки и файлы.

**Установка компонентов Windows, перезагрузка и реальные установки/удаления библиотек этой версии ещё не проверялись. Полная матрица Windows 10/11 и Server 2019+ не пройдена. Тестирование установщиков в VM намеренно не начиналось.** Ранее воспроизведённая проблема удаления .NET с повреждённой ARP-регистрацией остаётся отдельной нерешённой задачей.

Глобальный foreground в фоне не гарантируется Windows: 10 утверждений о передаче foreground в автоматическом прогоне не применялись при отсутствии foreground у лаунчера до действия. Обязательные проверки владельца, модальности, возврата и закрытия выполнены. Реальная смена DPI ОС и все конфигурации мониторов не проверялись.
