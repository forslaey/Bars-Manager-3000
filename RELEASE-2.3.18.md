# 2.3.18 — подтверждение установки программ

22.10.2026. Без подписи.

Оба дополнительных задания — ассоциации Notepad++/7-Zip и настройка постоянного пароля AnyDesk/RuDesktop — теперь по умолчанию выключены при каждом открытии модуля. В подтверждении установки больше нет безусловного предупреждения про удалённый доступ и ассоциации. Текст формируется по фактическим выбранным программам, их состоянию и дополнительным заданиям. При обновлении установленного выбранного клиента удалённого доступа предупреждение о разрыве сеанса остаётся независимо от галочки настройки пароля: это отдельное последствие обновления самой программы.

Причина исходного сообщения — общий статический текст, а не запуск дополнительных действий при снятых галочках. Исполнитель по-прежнему проверяет defaults.Checked и remote.Checked. Действия кнопки «Ассоциации файлов» по отдельному явному запросу сохранены.

SoftwareConfirmationTests: 21 проверка — обе темы, начальное/повторное открытие, Chrome отдельно, выбранные редакторы/архиватор, новый/установленный удалённый клиент, независимые опции. SoftwareMaintenanceTests: 32 проверки команд, версий, интерфейса и временных макетов; после ограничения sandbox повторены вне него. Установленные программы и настройки рабочего компьютера не менялись. Сборка baseline .NET Framework 4.6.
