# BARS Manager 3000 — 2.3.14, локальная сборка 21.10.2026

## Уточнение после испытания Telnet/TFTP пользователем

Исправлено ложное предложение обязательной перезагрузки после любого успешного изменения компонентов Windows. Теперь предложение зависит от подтверждённого результата обслуживания (RestartNeeded, передаваемого как код 3010) или состояний EnablePending/DisablePending. Результат сохраняется после каждого шага, в том числе если последующая операция или контрольное чтение завершается ошибкой. При возвращении из окна компонентов необходимость перезапуска передаётся менеджеру библиотек и сразу обновляет кнопку. Отказ от немедленной перезагрузки не сбрасывает этот признак в текущем окне менеджера. Пояснение недоступной кнопки теперь говорит об отсутствии обнаруженных признаков, а не гарантирует, что перезагрузка не требуется.

WindowsRestartTests: 30 проверок на подставных результатах и настоящих модальных preview-окнах, обе темы, возврат дочернего окна, сохранение признака и блокировка кнопки во время проверки системы. Реальные изменения компонентов и перезагрузка не выполнялись. По старому безусловному сообщению нельзя установить, требовалась ли перезагрузка в конкретном испытании пользователя.

Обновлённая сборка без подписи: bin/Bars Manager 3000 2.3.14.exe. SHA-256: 17907DE08D8B9D809D99EFBAA7DB7EA9E60FF5228CC1C7B5FE52BE4E5BA793FF. Прежняя локальная сборка сохранена в work/previous-builds.

## Остальные изменения

- В менеджере служб убраны обе строки под заголовком состояния: повтор имени/состояния и подпись специального режима установки. Освобождённое место занимает таблица. Заголовок показывает понятные фразы: «Служба зарегистрирована и работает», «…и остановлена», «…и запускается» и другие переходные состояния. Для нескольких регистраций показано их число, состояния остаются в таблице. Детали ошибок и предупреждений доступны в журнале, подробность текущего сообщения — при наведении на заголовок. Предупреждение об удалении нескольких регистраций доступно при наведении на кнопку удаления.
- Во всех исходниках убраны разделители `·` и `•` в интерфейсе и сообщениях. Используются подходящие по смыслу слова, запятые, двоеточия и точки с запятой; информация о версиях, разрядности и источниках сохраняется.
- В лаунчере отдельная кнопка «Инструкция». Встроенное окно содержит 12 разделов: службы, логи, библиотеки, отмена, компоненты Windows, программы, доступ, утилиты и объяснение Swagger. Слева разделы, справа текст с прокруткой; поиск по заголовкам и полному тексту, подсветка, счётчик, переход по всем совпадениям, Ctrl+F и F3/Shift+F3. Поиск без учёта регистра, пустой запрос возвращает все разделы. Доступно без интернета, обе темы, изменяемый размер окна.
- Проверены все семь окон с баннером BARS: лаунчер, службы, библиотеки, программы, компоненты Windows, утилиты и инструкция. Уже существовавший переход на https://www.datakrat.ru/ объединён в общий обработчик; везде одинаковые курсор, подсказка «Официальный сайт» и доступное описание ссылки. Иконки AnyDesk/RuDesktop в диалогах пароля не являются баннером BARS.
- Исследование проверки реального отклика: SERVICE-HEALTH-RESEARCH.md. Проверка возможна через согласованный диагностический API, но статус SCM/Swagger/порт не доказывает полную исправность. Реальный монитор и автоматические перезапуски этим этапом не добавлены; адреса API BARS пока не получены.

## Проверки и ограничения

UserGuideTests проверяет поиск, точные позиции совпадений после переводов строк, переход между разделами и по кругу, сброс, отсутствие результатов, темы, минимальный размер, состояния служб и сохранение ошибок в журнале, общую ссылку баннера и описание во всех окнах. LayoutFitTests и ThemeTests проверяют размещение и темы. Обновлены устаревшие ожидания тестов про удалённые нижние подписи. Проверки макетов выполняются с имитацией 100/125/150/200%; это не полноценные испытания всех аппаратных DPI.

Живое окно инструкции открывалось через кнопку лаунчера и просмотрено: текст отображается. RichTextBox не попадает в стандартный DrawToBitmap окна, поэтому пустое поле на технических PNG не означает отсутствие текста в живом окне. Тесты отдельно проверяют содержимое и выделение совпадений.

Сборка без подписи, включая встроенных помощников; подпись прежнего опубликованного 2.3.13 не переносится. Реальные установки/удаления, изменения служб, запросы к API BARS и VM не запускались. На GitHub изменения и новая сборка не публиковались. Существовавшее до начала работы локальное удаление EXE из releases/v2.3.13 сохранено.
