# BARS Manager 3000

Инструменты обслуживания рабочего места BARS: службы, библиотеки, программы и системные компоненты.

**[Скачать опубликованную программу](https://github.com/forslaey/Bars-Manager-3000/releases/latest)** · **[Руководство](docs/USER-GUIDE.md)** · **[История версий](CHANGELOG.md)**

**Текущий выпуск: [2.3.79](https://github.com/forslaey/Bars-Manager-3000/releases/tag/v2.3.79)** — с цифровой подписью. [Изменения и результаты проверок](docs/history/releases/RELEASE-2.3.79.md).

## С чего начать

1. Открой страницу последнего выпуска и скачай `Bars Manager 3000 x.x.x.exe`.
2. Запусти программу и выбери нужный модуль. Отдельная установка менеджера не требуется.
3. Для локальных пакетов используй комплект BarsManager3000 с подпапками _libraries, _soft, _tools и _wallpers. Офлайн-установщик Framework 4.8 лежит в _barsmanager3000. Получить комплект можно кнопкой «Скачать комплект».
4. Перед действием проверь выбор; после — результат и журнал.

## Возможности

| Модуль | Для чего нужен |
|---|---|
| Менеджер служб | Регистрация и удаление, запуск и остановка, режим запуска, сбор логов |
| Менеджер библиотек | Проверка версий и разрядностей, последовательная установка, удаление и журналы |
| Установщики .NET | Проверка сетевых версий и обновление локальных пакетов без установки в Windows |
| Установка программ | Google Chrome, Notepad++, 7-Zip, AnyDesk и RuDesktop |
| Распаковка утилит | Piglet, fiLinn, tftpd32 и WinSCP, ярлыки на рабочем столе |
| Первичные настройки | Проверка и применение согласованных системных настроек с подтверждением |
| Компоненты Windows | IIS, Telnet и TFTP; открываются из менеджера библиотек |
| Скачать комплект | Яндекс Диск и Google Диск, проверка файлов, загрузка оставшихся файлов из другого облака |

## Совместимость и текущая разработка

Точные требования опубликованной программы указаны в её выпуске. Текущая ветка переведена на .NET Framework 4.8 для Windows 10 21H2+, Windows 11 и Windows Server 2022 с рабочим столом. Полноценная проверка перехода ещё не завершена; целевые проверки интерфейса не заменяют полную проверку совместимости. Подробности и ограничения — в описании выпуска.

Скачивание пакетов не запускает их автоматически. Назначение приложений по умолчанию выполняется в штатных настройках Windows. Для изменения служб и системных параметров требуются права администратора.
