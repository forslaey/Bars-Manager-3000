# Версия 2.0.2 — 19.10.2026

Кнопки установки и проверки системы переставлены. При выделении установленной строки или отметке установленных компонентов главная кнопка называется «Переустановить/удалить выбранные» и предлагает два отдельных действия. Нажатие на строку использует эту строку; переключение чекбоксов возвращает действия для отмеченного списка. Удаление работает без каталога установщиков и использует зарегистрированные в Windows команды. Переустановка проверяет источник и деинсталляторы до начала; более новая установленная версия не понижается автоматически. При перезагрузке или неподтверждённом результате очередь приостанавливается.

RuntimePack: только установка, ключи -y -gm2 -fm0; удаления и переустановки нет. Общий достоверный признак наличия сборника по-прежнему отсутствует, поэтому он остаётся отдельным необязательным пакетом.

Лаунчер уменьшен до 820×540 логических пикселей; обе карточки используют одинаковые заголовки без внутреннего отступа текста и с одинаковой координатой начала.

Ограничения удаления: встроенный в Windows MSXML не имеет отдельного деинсталлятора. Для предварительных .NET, у которых запись Windows не позволяет точно сопоставить полную версию, операция останавливается до запуска. При отсутствии отдельного деинсталлятора файлы вручную не удаляются. Для .NET, зарегистрированного отдельными скрытыми MSI, удаляется соответствующий Runtime MSI; общие Host/Host FX Resolver не затрагиваются.

Полный набор предыдущих и новых проверок прошёл; после последних исправлений повторены 109 библиотечных, 46 проверок ввода/отрисовки и 43 проверки команд/сопоставления/диалогов. Реальные установщики, деинсталляторы и UAC не запускались. Отдельно прочитан реестр деинсталляторов этого компьютера. Сборка без подписи, .NET Framework 4.6.

Обнаружение набора VC++ в этом проходе не менялось: код сравнивает версию общего установщика 14.52.37025.0 с версиями компонентов 14.44.35211.0. Исправление требует отдельного уточнения состава набора; текущий статус не следует считать доказательством неудачной установки.
