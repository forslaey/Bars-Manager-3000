# Продолжение работы после очистки work

Очистка по просьбе пользователя: work уменьшена с 2799,52 до 25,22 МиБ (освобождено 2774,29 МиБ). Удалены скачанные тестовые комплекты Google/Яндекс, дубликаты EXE/DLL/ресурсов и временные бинарные fixture. Актуальная программа остаётся в bin, опубликованный выпуск — 2.3.56.

## Что сохранено локально
- work/current-verification: компактные результаты, подтверждения публикаций и снимки.
- Результат полного Google-прогона 180/180, SHA-256 проверены; сами скачанные установщики удалены.
- Уникальные журналы VM, материалы восстановления Git и исходники вспомогательных проверок. Личные журналы/состояние VM не публикуются в GitHub.

## На другом компьютере
1. Сохранить имеющиеся местные изменения и получить актуальный main через Git-Sync.ps1.
2. Для обычной разработки work не требуется: исходники в src, проверки в tests, ресурсы в assets.
3. Build.ps1 собирает программу. Готовый выпуск можно взять из GitHub Releases v2.3.56.
4. Тестовые EXE и fixture воспроизводимы; для EXE/MSI-макетов используется tests/New-BundleFixtures.ps1. Целевые проверки — tests/Run-ReviewRegression.ps1 (имена и результаты в RELEASE-2.3.56.md и предыдущих описаниях).
5. Полные облачные прогоны создают большие копии в work; выполнять только при необходимости и не запускать скачанное содержимое автоматически.

Последний полный Test.ps1 успешным не объявлялся. Следующий онлайн-этап — проверка Яндекса по отдельному указанию пользователя. Физические испытания КСО отложены; каталог BARS вне спринта.
