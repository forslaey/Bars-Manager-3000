## Развёртывание на другом компьютере (20.10.2026)

Диски и снимки VM между компьютерами не переносятся. На новом ПК лабораторию создают скриптами из tools/lab (Windows PowerShell 5.1 от администратора, Hyper-V включён и после перезагрузки работает vmms):

```powershell
.\tools\lab\Test-LabPrerequisites.ps1 -IsoPath <ISO> -SkipHash      # только чтение
.\tools\lab\New-LabVM.ps1 -IsoPath <ISO> -ExpectedSha256 <SHA256>    # создаёт и запускает VM
.\tools\lab\Finalize-LabVM.ps1                                       # снимок Clean-Windows, VM выключается
.\tools\lab\Copy-LabInputs.ps1                                       # артефакты в C:\Lab\Input гостя
```

Нужны: полностью скачанный ISO (облачные заглушки отвергаются), ≥60 ГБ свободного места, отсутствие VM BARS-Test-W11 и непустой папки C:\BARS-TestLab\BARS-Test-W11. Тестовая сборка из Build.ps1 и Net6-Integration.exe кладутся в work\lab-build (игнорируется Git); артефакты собирает пользователь или агент заранее. Учётные данные защищены DPAPI и подходят только тому же пользователю Windows на том же ПК.

Фактическая конфигурация и результаты второго развёртывания — в DEVELOPMENT-STATE.md (раздел «Вторая тестовая лаборатория»).

## Доступ и повторение

В Windows PowerShell 5.1 от администратора:

```powershell
Start-VM -Name BARS-Test-W11
# Выполнить подготовленный гостевой скрипт (запуск происходит внутри VM):
.\tools\Invoke-TestVM.ps1 -ScriptFile .\tests\integration\Run-Net6.ps1
```

`Run-Net6.ps1` действительно устанавливает и удаляет компоненты, проверяет гостевое имя и Microsoft-подписи файлов. В обычный Test.ps1 он намеренно не включён. Перед повторением нужно вернуть чистый снимок и скопировать актуальный Net6-Integration.exe, собранный из `tests/integration/Net6Integration.cs`, в `C:\Lab\Input` гостя. Локальные вспомогательные скрипты первого развёртывания сохранены в `work/`; они не являются универсальным установщиком VM и не должны запускаться заново поверх существующей VM/VHDX.

## Обязательная последовательность

1. Дождаться установленной Windows и убедиться, что PowerShell Direct работает именно с `BARS-LAB-01`.
2. Удалить из гостя временный файл ответов установки и сохранённый пароль автологина. Исходный случайный пароль остаётся только в DPAPI-файле хоста.
3. Снять исходную инвентаризацию гостя: ОС, пакеты MSI/ARP, .NET обеих разрядностей. Проверить отсутствие исследуемых .NET 6 перед опытом.
4. Создать проверенную точку `Clean-Windows`. Не откатывать и не удалять чужие VM/снимки.
5. Копировать в VM только текущую неподписанную программу, тестовые инструменты и нужные установщики. Сверять SHA-256 перед запуском.
6. Воспроизвести пользовательскую проблему со штатными .NET 6.0.36 x86/x64: установка, независимая проверка runtime/регистраций, удаление через код менеджера, независимая повторная проверка. Сохранять команды, коды, журналы и состояние до/после.
7. После воспроизведения исправлять выбор владельца/команды удаления; не обходить зависимость вслепую через IGNOREDEPENDENCIES или стирание реестра/каталогов.
8. Повторить опыт после исправления, а затем проверять обновление, переустановку, разные владельцы общего runtime, отмену и перезагрузку. Для следующего семейства возвращаться к понятному снимку.

Автоматические проверки кода сохраняются как отдельный уровень. Их число не является подтверждением реальной установки или удаления стороннего пакета. Сквозной результат отмечается подтверждённым только после фактического изменения состояния гостевой ОС.

## Диагноз на хосте, только чтение

В операции ASP.NET Core 6.0.36 x64 от 19.10.2026 MSI дошёл до WixDependencyCheck, запросил подтверждение из-за существующих зависимостей и вернул 0, сохранив регистрацию. Сами runtime 6.0.36 доступны через dotnet --list-runtimes. Установлены внутренние MSI; ссылки на старые bundles есть в Installer\Dependencies, а соответствующие внешние ARP-записи отсутствуют. Происхождение рассогласования пока не установлено. Разрушительная коррекция хоста не выполнялась.

Текущее фактическое состояние VM и результаты испытаний записывать в DEVELOPMENT-STATE.md; этот план сам по себе не означает успешного завершения перечисленных шагов.
