BARS Manager 3000 — сборка 2.1.0

1. Открой PowerShell в папке проекта (обычно C:\ServiceManager3000).
2. Обычная сборка БЕЗ подписи:

.\Build.ps1

Результат: bin\Bars Service Manager 3000.exe. Это общий лаунчер с двумя модулями.
Встроенные помощники тоже будут без подписи. Не добавляй -Sign, если подпись не нужна.
Скрипт использует reference assemblies .NET Framework 4.6; при первой сборке нужен интернет.
Исходники рассчитаны на встроенный компилятор C# .NET Framework, Visual Studio не требуется.

3. Проверки (не устанавливают и не удаляют настоящие библиотеки/службы):

.\Test.ps1

Тест отмены запускает и завершает только собственные инертные процессы.
Защищённые именованные события нужно проверять под обычной учётной записью Windows,
без урезанного токена песочницы; права администратора для самих тестов не требуются.

Если PowerShell блокирует локальные скрипты и политика не задана организацией,
для своего пользователя один раз можно выполнить:
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

4. ТОЛЬКО если решил подписать сборку прежним сертификатом с закрытым ключом:

.\Build.ps1 -Sign -CertificateThumbprint '5E05A9087A2BA3FF1186A72825CCA1B40B73B7EB' -OutputDirectory '.\signed'

Результат: signed\Bars Service Manager 3000.exe. Сначала подписываются оба встроенных
помощника, затем общий EXE. Без прежнего закрытого ключа эта команда не сработает.
Пароли и закрытые ключи в GitHub не загружай.

Пошаговые инструкции по подписи, её проверке и сведениям об авторе:
ПОДПИСЬ-ПОШАГОВО.txt

При публикации изменений оба файла ПОДПИСЬ-ПОШАГОВО.txt и СКОМПИЛИРОВАТЬ.txt
должны оставаться в репозитории.
