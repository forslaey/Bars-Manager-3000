# 2.3.56 — целые строки при прокрутке .NET

Без подписи, .NET Framework 4.6. В установщиках .NET viewport ограничен целым числом равных строк через существующий GridViewportLayout. Пересчёт отложен после изменения ширины столбцов/окна/списка и видимости полосы. Это устраняет частично видимую следующую строку при промежуточной прокрутке; 2.3.54 исправляла только пустой фон в конце. Короткий список занимает только высоту строк; свободное место снаружи имеет фон окна. Боковые границы сохранены.
