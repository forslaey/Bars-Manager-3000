# История изменений BARS Manager 3000

Подробные изменения, проверки и ограничения доступны в файлах каждого выпуска. Отдельный номер локальной версии не означает, что для неё создавался релиз на GitHub.

| Версия | Изменения | Подробности |
| --- | --- | --- |
| 2.3.20 | Ассоциации Chrome, компактные лаунчер и утилиты, закрепление тумблера служб, единая тема рамок и размещение заголовков, таблица программ без внешней карточки. Выпуск без подписи; публикация запрошена 23.10.2026. | [2.3.20](RELEASE-2.3.20.md) |
| 2.3.19 | Единая таблица первичных настроек, передача PowerShell через stdin, стабильность сенсорного списка. Опубликован общий выпуск с накопленными исходниками предыдущих версий. | [2.3.19](RELEASE-2.3.19.md) |
| 2.3.18 | Дополнительные галочки программ выключены при открытии; подтверждение учитывает фактические задания и обновление удалённых клиентов. | [2.3.18](RELEASE-2.3.18.md) |
| 2.3.17 | Автоматические журналы библиотек, сенсорная прокрутка, SmartScreen и права DataKrat/Bars по явной кнопке. | [2.3.17](RELEASE-2.3.17.md) |
| 2.3.16 | Первичные системные настройки, Chrome, подтверждение паролей и стандартный пароль по явному выбору. | [2.3.16](RELEASE-2.3.16.md) |
| 2.3.15 | Исправление DPI списка разделов инструкции. | [2.3.15](RELEASE-2.3.15.md) |
| 2.3.14 | Встроенная инструкция с поиском, подписи состояний, единые ссылки баннеров; исследование отклика служб. | [2.3.14](RELEASE-2.3.14.md) |
| 2.3.13 | Подписанный опубликованный выпуск, загрузки в _soft, переиспользование пакетов и статичное поле режима запуска. | [2.3.13](RELEASE-2.3.13.md) |

2.3.14–2.3.18 не оформлялись отдельными GitHub Releases. Накопленные исходники вошли в опубликованную 2.3.19; GitHub не создаёт отдельную запись истории для каждой локальной смены номера. README ранее оставался на 2.3.14 — он актуализирован вместе с этим журналом.
