# 2.3.49 — точечная компоновка загрузчика и диалогов

Без подписи, .NET Framework 4.6. Только UI; транспорт не менялся и Яндекс не запрашивался.

- «Папка комплекта», поле и кнопка в одной строке; вертикальные центры совпадают. Отступ от заголовка увеличен, нижние элементы перемещены вверх, фиксированное окно 650×530. Интервалы журнала/пояснения/прогресса сохранены.
- В выборе облака добавлен промежуток перед кнопками.
- Подтверждение остановки загрузки использует отдельный компактный режим BrandMessageDialog 520 px шириной, с вертикальным центрированием знака/текста. Измерение переноса учитывает меньшую ширину; текст не обрезается. Остальные сообщения сохраняют прежние размеры.

- У кнопки «Удалить» программ снято особое destructive-оформление; размеры шести действий остаются равными.
