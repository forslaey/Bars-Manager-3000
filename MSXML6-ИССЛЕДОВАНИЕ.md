# MSXML 6.0: результат поиска, 22.10.2026

На скриншоте пакет имеет версию 6.10.1129.0, а обнаруженная системная DLL — 6.30.19041.5794. Это разные способы поставки одного семейства MSXML 6.0: самостоятельный старый пакет и компонент Windows. Номер встроенной DLL зависит от версии и обновлений Windows. Поиск универсального актуального MSI 6.30.19041.5794 для Windows 10/11 и Server 2019+ не дал результата; отдельного поддерживаемого установщика этой версии не найдено.

Microsoft прямо указывает, что MSXML 6.0 входит в Windows Vista и более поздние ОС, а самостоятельная перераспространяемая поставка предназначалась для XP/Server 2003. Сервисное обслуживание встроенного компонента связано с обслуживанием Windows.

- [Официальная схема поставки и поддержки MSXML](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/jj152146(v=vs.85))
- [Что нового в MSXML — поставка вместе с Windows](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ms753751(v=vs.85))

Найдены официальные пакеты обновления MSXML 6.0 SP2 KB2957482 (старые ОС):

- [x86, Microsoft Download Center](https://www.microsoft.com/ru-ru/download/details.aspx?id=43199) — msxml6-KB2957482-rus-x86.exe.
- [x64, Microsoft Download Center](https://www.microsoft.com/ru-ru/download/details.aspx?id=43253) — msxml6-KB2957482-rus-amd64.exe.
- [Бюллетень Microsoft MS14-033: применимость и разрядности](https://learn.microsoft.com/en-us/security-updates/securitybulletins/2014/ms14-033).

Это обновления для старой платформы, а не «свежий MSXML для Windows 10/11». Дата повторной публикации страницы не означает новый выпуск DLL. В комплект Библиотеки эти файлы не добавлялись, существующие файлы не заменялись.

Для поддерживаемых менеджером Windows актуальную встроенную версию нужно получать обновлением самой Windows. На Windows x64 присутствуют системные компоненты обеих разрядностей; их обслуживание выполняет Windows. Не нужно копировать отдельные DLL с другого компьютера или понижать системную 6.30 старым MSI. Сообщение менеджера «Установлена новее; предоставлен Windows; отдельное удаление не требуется» в этом случае соответствует ситуации.
