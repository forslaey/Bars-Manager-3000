# 2.3.43 — надёжность и обслуживание загрузчика комплекта

Без цифровой подписи; .NET Framework 4.6. Установщики загрузчиком не запускаются.

## Реализовано
- Повторы временных ошибок API и передачи, включая короткий ответ и ошибку чтения потока. Неверный SHA-256 сохраняется в карантине, повтор ограничен. Content-Range проверяется целиком.
- Скорость учитывает только байты, действительно прочитанные из сети, отдельно от сохранённых частей. Отображаются стадии скачивания, сверки SHA-256, публикации и ожидания повтора; прогресс активной строки закрашивается.
- Необязательный режим «Авто» уменьшает число новых параллельных заданий при сетевых повторах (уже начатые передачи не обрывает). Верхняя граница по-прежнему 1–4.
- Сохранение очереди по пути и хешу; после нового чтения актуального источника предлагается восстановление выбора. Изменившееся содержимое не восстанавливается автоматически.
- Журнал этапов и ошибок в .bars-download/transfer.log с ограничением размера. Кнопка открытия журнала.
- Служебное имя .bars-download запрещено в удалённом каталоге. Очистка частей и карантина выполняется отдельно с подтверждением, без обхода ссылок и удаления неизвестных файлов/квитанций.
- Для обновления EXE/MSI используются существующие правила LibraryDiscovery/SoftwareCatalog: продукт, архитектура, семейство/ветка и версия. Неизвестная идентичность запрещает замену. Для переименованных распознанных пакетов проверяются более новые версии в том же каталоге.
- Отдельная подтверждаемая очистка старых неизменённых файлов с квитанцией, отсутствующих в актуальном источнике: только при уже скачанной и сверенной более новой версии той же идентичности. Утилиты, неизвестные и изменённые файлы не очищаются. Перед удалением состояние проверяется повторно.
- Готовый совпадающий файл распознаётся при повторе после ошибки записи квитанции; сбой квитанции сообщается отдельно от результата сохранения файла.
- Общая сохранённая папка загрузчика, передача текущего корня из программ, отсутствие изменения источника при простом закрытии окна без проверки.
- Проверка места учитывает имеющиеся части. Исправлена отрисовка подписей BrandCheckBox при DrawToBitmap (сохранение graphics transform).

## Проверки и ограничения
Целевые исходники тестов пересобраны: BundleTests 29, BundleTransportTests 22, BundleLayoutTests 72 (две темы, моделирование 100/125/150/200%), NavigationTests 167, SoftwareConfirmationTests 18, TouchGridTests 39, LibraryManagerTests 155, UserGuideTests 475, TouchTextTests 11, метаданные команд 39. Это не полный Test.ps1.

Полный онлайн-прогон: 187 файлов в дереве, 166 получены/проверены (1 336 730 436 байт), 21 ошибка HTTP 500 после повторов. Пользователь подтвердил временные проблемы Яндекса; повтор массового скачивания отложен. Скачанные файлы не запускались. Эти результаты не означают успешную полную загрузку.

SoftwareStorageTests не прошёл из-за отсутствующего внешнего fixture C:\Библиотеки\_soft; SoftwareTests остановился на проверке Useful action button height. Эти проверки не объявляются успешными. Старые ограничения Base64/Ui2330 не устранены.

Не считать все пункты большого плана завершёнными: каталог продуктов BARS и зависимостей не реализован (нет согласованного состава/метаданных); криптографически подписанного манифеста источника нет; SHA-256 API подтверждает совпадение с источником, а не издателя. Полная матрица сбоев квитанций/носителей и реальных обновлений EXE/MSI, физический сенсорный экран, отключение флешки и сетевые файловые системы не испытаны. Сравнение переименованных пакетов ограничено одним каталогом. Уменьшение параллельности не повышает её обратно автоматически. Автоматической установки или зеркального удаления локальных файлов нет.
