# BARS Manager 3000 2.3.35 — самостоятельные окна модулей

27.10.2026. Программа и оба встроенных помощника без цифровой подписи.

## Навигация

- При открытии одной из пяти основных карточек окно лаунчера действительно закрывается и освобождается, а не скрывается и не остаётся заблокированным владельцем. Модуль открывается как самостоятельное немодальное главное окно, его можно сворачивать.
- «В меню» закрывает модуль и создаёт новый лаунчер. Крестик модуля завершает приложение после предусмотренных модулем предупреждений/отмены; отменённое закрытие не переключает окно.
- Жизненным циклом управляет ManagerApplicationContext, а не окно лаунчера. Сначала уничтожается старое окно, затем создаётся следующее; один общий цикл сообщений сохраняется до выхода. Прямой запуск служб и перетаскивание EXE используют тот же механизм возврата.
- Инструкция и «О программе» из лаунчера, а также компоненты Windows из библиотек остаются вложенными диалогами: закрытие возвращает в их непосредственное родительское окно. Системное завершение работы не открывает меню заново.
- Конструкторы модулей вызываются после закрытия лаунчера, а не во время его существования. Ошибка создания окна показывается и завершает контекст без скрытого зависшего лаунчера.

## Проверки

NavigationTests: 152 проверки пяти preview-модулей, трёх циклов возврата каждого, отсутствия лаунчера в OpenForms, уничтожения HWND, сворачивания, отменённого закрытия, выхода крестиком, настоящего Application.Run, прямого запуска служб, фабрик пяти карточек и вложенных диалогов инструкции/компонентов. Установщики, управление службами и применение системных настроек не выполняются.

Дополнительно прошли UserGuideTests 475, Ui2332Tests 533, LayoutFitTests 1684, SoftwareTests 336, UtilityModuleTests 559, RegressionTests 89 (включая busy close), LibraryCancellationTests 14, LibraryManagerTests 155, SoftwareConfirmationTests 18, проверки метаданных команд Windows 39. Отмена/Job Object проверялись только на инертных собственных процессах. Оконные тесты не заменяют многочасовое ручное испытание реальных установок.

Сборка: .NET Framework 4.6, bin/Bars Manager 3000 2.3.35.exe. Тема читается из существующего сохранённого предпочтения при создании нового окна. Пользовательские тексты и содержимое инструкции не изменялись.

Полный Test.ps1 не запускался. Прежние ограничения PowerShell Base64 в текущем окружении и старого DPI-теста Ui2330 остаются; эта навигационная правка их не исправляет. Реальных установок, изменений политик/служб, VM, перезагрузки не было.

Релиз содержит только EXE, RELEASE-2.3.35.md и CHANGELOG.md; публикация подтверждается отдельно после проверки GitHub.
