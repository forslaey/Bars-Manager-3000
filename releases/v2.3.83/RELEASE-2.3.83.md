# BARS Manager 3000 2.3.83

Накопительное обновление после 2.3.79. В комплект входит один EXE с Rust-запускателем и цифровой подписью Authenticode с меткой времени.

| Раздел | Изменения |
| --- | --- |
| SQL Server и SSMS | Загрузка наборов, распаковка и запуск штатных мастеров. |
| Утилиты | Отдельные каталоги Google и Яндекса, поддержка ZIP, RAR и 7z. Для RAR и 7z нужен системный tar.exe. При сбое окно перечисляет проблемные архивы. |
| Файлы и папки | Двойное касание и боковые кнопки мыши для перехода по истории. |
| Службы | Уточнены проверка совместимости агента фискализации, отмена ожидания и сообщение Windows 1064. |
| Справка | Обновлены встроенная инструкция и руководство пользователя. |
