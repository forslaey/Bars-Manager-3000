# Bars Manager 3000 2.3.20

Неподписанная программа с двумя встроенными помощниками. [Релиз GitHub](https://github.com/forslaey/Bars-Manager-3000/releases/tag/v2.3.20).

Ассоциации Chrome, единые темы строк заголовков, выровненные названия модулей. Компактная область только у лаунчера и утилит; остальные модули растягиваются. Таблица программ без внешней карточки. Подробности, проверки и ограничения — RELEASE-2.3.20.md. История начиная с 2.3.14 — CHANGELOG.md.

Инструкции СКОМПИЛИРОВАТЬ.txt и ПОДПИСЬ-ПОШАГОВО.txt включены. Подписание — только отдельным явным действием. SHA-256 программы указан в SHA256SUMS.txt. Внешние установщики, пользовательские настройки и сертификаты не входят в выпуск.
