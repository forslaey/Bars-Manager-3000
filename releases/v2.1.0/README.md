# BARS Manager 3000 2.1.0

Готовая переносимая сборка Windows: **Bars Manager 3000.exe**. В неё входят оба модуля и помощники x86/x64.
Файл и встроенные помощники не подписаны. SHA-256 приведён в SHA256SUMS.txt.

Это проверенный бинарный файл версии 2.1.0.0; 1829 автоматических проверок пройдены.
Отмена внешнего установщика не гарантирует откат; перед массовым использованием проверь очередь на VM.
