# BARS Manager 3000 2.3.78

Сборка для Windows на .NET Framework 4.8, без цифровой подписи.

## Что изменилось

| Раздел | Изменения |
| --- | --- |
| Лаунчер | Остаётся доступным при открытых модулях. Каждый модуль открывается в одном экземпляре. |
| Службы BARS | Проверка выбранного файла, уточнённые сообщения об установке, запуске и удалении, диагностика локального HTTP-отклика. |
| Логи программ BARS | Выбор запущенного приложения, файла или папки. Сбор логов в ZIP переиспользует механизм менеджера служб. |
| Библиотеки и .NET | Сканирование ограничено корнем выбранной папки и каталогом Microsoft .NET. Обновления установщиков проверяются и записываются отдельно от установки в Windows. |
| Интерфейс | Исправлена компоновка при разворачивании окон и масштабировании. Обновлены прогресс, полосы прокрутки и встроенная инструкция. |
| Проверки | Актуализированы тесты навигации, выбора, автообновления служб и размеров окон. Добавлены регрессионные проверки. |

## Границы проверки

Автоматизированные проверки покрывают приложение и имитации операций. Реальные установки и удаления, изменение системных политик, живые облачные загрузки и физический КСО в этом выпуске отдельно не проверялись.
