# 2.3.64 — диагностика служб и Swagger

Добавлены локальные диагностика и окно отклика: readonly адрес без dropdown, три равные кнопки «Проверить отклик», «Открыть Swagger», «Назад», периодическая проверка. HTTP Ping Banking сохраняется; остальные подтверждённые порты проверяются TCP без полезной нагрузки. HTTP.sys сопоставляется с PID очереди, а не произвольными портами PID4. HTTP405 означает ответ сервера без подтверждения Ping, не зависание.

Swagger ищется по подтверждённому адресу в swagger/index.html и index.html, HTML проверяется на признаки Swagger UI. Реальная Payment0.14.1 ранее ответила200 по /index.html и /swagger/v1/swagger.json,404 по /swagger/index.html. Повторный автоматический PaymentLiveTests не выполнен успешно: процесс уже закрыт; прежний VM file-not-found не относится к доказанной ошибке установки хоста. При закрытии окна поиск Swagger отменяется.

Реальный стенд: Banking Ping/Swagger подтверждены; Scanner/License TCP; MobileCashDesk HTTP.sys8881/HTTP405, Swagger не обнаружен. WebStore/MobileService без подтверждённых сетевых адресов. Конфиги читаются из Config.xml, WCF, appsettings и configs/appsettings. Не обещать поддержку любых конфигураций, дочерних процессов, всех локализаций netsh, нестандартных Swagger/auth/HTTPS. Полный аудит39 пакетов не завершён; платёжные бизнес-методы и изменения БД не выполнялись.

Финальные проверки: HTTPsys3, hosting3, probe11, TCP7, UI4, navigation167, metadata39. Обе темы UI созданы тестами; тёмный снимок просмотрен ранее. Полный Test.ps1/физический touch не выполнялись. Framework4.8, без подписи.
