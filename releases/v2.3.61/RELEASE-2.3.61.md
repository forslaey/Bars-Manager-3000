# 2.3.61 — накопленные изменения Framework 4.8 и первичных настроек

Включены накопленные локальные изменения из другого клиента: целевая платформа основного EXE/помощников .NET Framework 4.8, фиксированные бегунки таблиц/журналов/инструкции, правки границ и документации. Минимальные ОС: Windows 10 21H2 и Windows Server 2022 с рабочим столом.

В окне первичных настроек: настоящие переводы строк состояния преобразуются в «; », включён перенос состояния, высота всех семи строк учитывает все три колонки. Удалён опасный перерасчёт MinimumHeight внутри событий изменения колонок; расчёт выполняется отложенным общим механизмом только для этого окна. Отступы таблица–кнопки и кнопки–видимая карточка журнала равны (31px в проверенном DPI, обе темы). Под кнопки не резервируется пустая растянутая строка. Настройки и команды Windows не менялись.

Исторические RELEASE-*.md перенесены из корня в docs/history/releases; опубликованные GitHub Releases не удаляются.

Проверки: SettingsSpacingTests6, UtilityModuleTests583, GridViewportTests208, JournalScrollTests42, метаданные команд39. Проверки выполнялись без применения политик, установки компонентов и перезагрузки. Снимок первичных настроек просмотрен; прежняя ошибка перерасчёта в повторных preview-прогонах не воспроизвелась.

Ограничения: полный Test.ps1 не запускался; перенос Framework 4.8 ещё не прошёл полноценную VM-матрицу минимальных ОС/производительности/установки служб. Исторические ограничения Base64 и общих UI-тестов не объявляются устранёнными. Полная загрузка облачного комплекта и физический сенсорный экран в этом проходе не проверялись. Сборка без подписи.
