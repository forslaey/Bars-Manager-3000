# BARS Manager 3000 2.3.13

Подписанный переносимый выпуск: `Bars Manager 3000 2.3.13.exe`. Встроенные помощники x86/x64 также подписаны прежним сертификатом автора, с SHA-256 и метками времени. Закрытый ключ в комплект не входит. Подпись самоподписанным сертификатом не создаёт автоматического доверия Windows на другом компьютере.

SHA-256: `25CB78D0332CF2E01714EA4BF0F48900BA8614CA7B59839E04436A62CE7B8CB9`.

[Изменения и проверки](../../RELEASE-2.3.13.md) · [GitHub Release](https://github.com/forslaey/Bars-Manager-3000/releases/tag/v2.3.13).

Скачанные установщики сохраняются в `_soft` выбранной папки библиотек. Сам менеджер можно хранить отдельно или на флешке. При отсутствии выбранного источника загрузка запросит папку. Проверка версий не загружает установщики.
