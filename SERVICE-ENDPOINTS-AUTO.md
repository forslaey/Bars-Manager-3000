# Автоматические адреса служб — 03.11.2026

В менеджере служб добавлена видимая кнопка «Диагностика» в основной ряд действий. Старое контекстное меню удалено. Окно наследует тему, переключателя темы нет. Адрес больше не вводится вручную: список заполняется подтверждёнными адресами диагностики.

## Определение адресов

ServiceCatalog сохраняет PID из EnumServicesStatusEx. ServiceEndpoints читает GetExtendedTcpTable для IPv4/IPv6, только LISTENER с OWNER_PID. Показывает все слушающие TCP-адреса/порты выбранного процесса. Для общего процесса нескольких служб диагностика не назначается автоматически. Остановленная служба не получает фиктивный действующий адрес. HTTP.sys/дочерние процессы автоматически не приписываются службе.

Не каждый TCP-порт является HTTP. Для Banking профиль сопоставляет HTTP Urls в configs/appsettings.json и configs/appsettings.Production.json с IPv4 loopback/wildcard слушателями данного PID и использует /Info/Ping. Адрес нормализуется на127.0.0.1. Другие семейства пока показывают порты и пояснение, что безопасный метод не подтверждён. IPv6 слушатели показываются, но автоматическое назначение HTTP по IPv6 в первом профиле не реализовано. При нескольких кандидатах пользователь выбирает подтверждённый адрес из списка. При повторной проверке заново читаются служба, PID, конфигурация и таблица портов. Абсолютной атомарности между проверкой PID и соединением нет; при высокой сменяемости процессов нужна дополнительная защита.

## Проверка на реальном компьютере

Banking: PID5376, слушатели127.0.0.1:5126 и[::1]:5126. Автоматически найден http://127.0.0.1:5126/Info/Ping, получен HTTP200 и Pong. Окно в двух темах создано тестом; конечный снимок тёмной темы просмотрен: адрес подставлен, результат получен. Native PID-привязка проверена отдельными IPv4/IPv6 TcpListener на портах выделенных ОС. Остановленная ATOL только прочитана, не запускалась. 11 сценариев ответов/таймаута/отмены/запрета внешнего адреса прошли повторно.

Ошибка инициализации Devices/{id} при отсутствии терминала не равна зависанию API. Прямой опрос терминала не включён в автоматический профиль; оплаты, возвраты, сверка итогов и операции карт не вызывались.

## Ограничения

Пока готова автоматическая диагностика отклика только Banking. Не реализованы профили устройств/прочих служб, порог нескольких последовательных сбоев, сохранение профилей и отдельная колонка отклика в основной таблице. Снимок основного окна с шестью кнопками отдельно не проверен. Переключатель периодического опроса доступен только при найденном адресе. Окно закрыто — проверки прекращаются. HTTPS автоматически не используется, сертификаты не обходятся.
